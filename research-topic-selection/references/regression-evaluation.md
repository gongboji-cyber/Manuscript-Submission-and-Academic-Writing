# 选题系统回归测试：既防假 GO，也防假 STOP

本协议用于 Skill 修改后的校验，也可用于大批量选题的抽样质控。任何模型对以下场景的答复须**实际引述近邻证据与确定的适用范围**，不能根据此清单直接套答案。静态脚本只能证明裁决结构一致，不证明科学观点正确。

## A. 六个必须通过的历史反例

| 编号 | 输入提示或危险主张 | 预期发现的错误 | 不可接受的行动 |
| --- | --- | --- | --- |
| R1 近优 GRN | 基准分接近但 regulon 差异很大，可否原创投稿？ | 忽略较早的分歧先例、依赖内部评分及缺独立扰动真值 | 直接 GO_FULL 或换图重投 |
| R2 CCC | PBMC 标签/LR 置换及 FPR 检查是否足以新论文？ | 漏掉 FastCCC/RobustCCC/ESICCC/LIANA，混淆 FPR 与 type-I error | 用同一组合直接 GO |
| R3 多组学 | 比较 MOFA+/totalVI/WNN 输出多少共享因子？ | 将不可比估计量当共同真值，漏经典因子过拟合研究 | 跳过 G2 启动试点 |
| R4 虚拟筛选 | 用口袋置信度做弃权、提升命中率 | 漏 AANet/TASC 等近邻，未定义固定预算/再分配/真实 regret | 无 G1/G4 直接 GO |
| R5 DMS | 一项总体功能测量就拆分折叠稳定性与功能 | 未检验潜变量不可识别/测量误差，漏早期全局表型模型和近期直接实验 | 未有正交测量就声称机制已证明 |
| R6 假 STOP | 某预印本提到相似方法、某筛选子集只 7 个阳性靶标，另一资源 403 | 以题名相似判全部覆盖；以子集代全数据；以访问失败判世界无数据 | 以不充分证据宣告全题 STOP |

每个案例同时评估：是否引用真正**对应主张的**论文 Methods/Results/关键补充；是否说明估计量和独立单位；是否核验数据联合交集；证据不足时是否准确 HOLD。不要硬编码这些历史选题必然永远 STOP，新独立证据可能改变决定。

## B. 必须容许正例，不把保守误当质量

至少加入两类合成或新实证正例：

1. 近期可信直接前作已完整审读，新增的估计量或干预可被独立测量；有版本明确的数据键/足够独立单位、强基线、冻结预算与区间方案，G0–G4 各有来源。`GO_MINIMAL_PILOT` 应可通过，即使试点尚未运行。
2. 上述通过者已按冻结方案真正运行、G5 经复核 PASS、结果达到事前 δ 且无致命偏差；`GO_FULL_STUDY` 才可能通过。若试点未运行或不合格，不准过 G5。

这些是逻辑单元测试，不是虚构真实发现；标注 `SYNTHETIC`，不得混入正式候选。

## C. 双向审查规则

- **假 GO 错误**：文献未深审、零模型定义不当、G2 estimand 不同、G3 联合交集没核验或 G4 不可比较时仍许可试点。
- **假 STOP 错误**：以摘要/题名相似替代实质覆盖证据、将访问障碍当科学无数据、把测量受限当所有可修复路线均无效、超出研究子集泛化。
- **遗漏新意错误**：看到既有方法名称就 STOP，却没有比较新测量、新独立干预、不同 estimand 或使用场景下的独立实用价值。
- **方法前作漏检**：只找同一应用关键词，漏古典统计、测量误差/可靠性、生物物理理论的本质相同方法。
- **假充分证据**：来源仅为二手摘要却标 `fulltext-supp-reviewed`；数据资源仅题录或未经联结却标 `ELIGIBLE`。

报告每项失败的案例号、错误关口、证据和修复；计算假 GO、假 STOP 数量与未知拒绝率。两种误判均需逐案归因，不用“判 STOP 越多越好”优化模型。

## D. 每次升级的最小回归步骤

1. 用 `python3 -m unittest discover -s research-topic-selection/tests -v` 运行静态行为测试。
2. 用 `python3 research-topic-selection/scripts/validate_gate_ledger.py research-topic-selection/assets/gate-ledger-example.csv` 检查样例格式和状态合法性。
3. 做至少 R1–R6 与两类正例的**盲复审**：检查事实，不能仅要求模型背诵本清单；必要时更新最新文献。
4. 抽样复核全量漏斗：随机取被淘汰者和近阈值者，重审是否误丢；全部被深审的 GO 必须复核对应直接前作与关键文件。
5. 汇总版本差异：证据覆盖率、G1/G2/G3 不明比例、可核验 PASS 数、两类误判数、额外检索成本；回归未过不得声称质量改进已证实。

所有历史与合成案例均不得作为当前项目实际试点或数据访问的证据。
