# 开题资格最易漏掉的关口：可识别性、联合交集与独立信息

## G2：先写统计/生物学命题，再选择方法

每个候选用可检查的五元组表示：`(单位, 干预/暴露或条件, 观测, estimand, 识别假设)`。区分：

- 可观测量（例如 DMS 总体适应度）和潜变量（折叠稳定性、表达、催化活性），以及是否需要重复/正交测量。
- 相似名称的方法是否估计相同量：若 MOFA+ 共享因子、totalVI 联合潜变量和 WNN 权重并无共同可识别参数，就不能统一比较“共享因子数”。
- 第一类错误率 `P(reject H0 | H0 true)` 与经验 FPR `FP/(FP+TN)`、置换后稳定性及统计检验内部随机置换之间的差别。
- 生物学个体/实验批次与数据表中的行、细胞、突变数之间的独立性差异。

画至少一个**反例/对立生成机制**：是否可存在参数 `θ1≠θ2` 却在现有数据下生成相同观测分布？若能，列额外测量或假设；如果可通过实测补充则 HOLD，不能原地宣告不可识别的机制结论。若无需共同 estimand 才能开展研究，就分别定义问题，不能强行构造一个“统一排名”。

对干预/因果命题列出混杂、选择、测量误差和反馈路径；对多组学/结构/虚拟筛选列出对象映射、取样机制与评分机制。必要时先做纸面证明、小的确定性反例或独立统计复核，不需运行完整模型。

## G3：母集规模不是可分析分母

资格核验必须与最终分析设计使用**同一 join 规则**。为每个数据资源标记：

| 层级 | 核查事实 |
| --- | --- |
| ACCESSIBLE | URL/版本/许可、实际下载和解析（如未执行写 NOT_TESTED） |
| JOINABLE | 真实配对键：实验 ID、目标/配体、蛋白/变异、细胞型/供体/扰动、结构、时间点；去重及不匹配原因 |
| LABELLED | 结局、阴性/阳性、对照、检测限、质量标准和缺失机制 |
| ELIGIBLE | 真值独立、训练/基准/文献先验不泄漏、纳排规则对估计量有效 |
| POWERED | 完整 join 后各组实际有效独立单位、分层与事件数、拟达到的估计精度 |

例如化合物筛选：不能用 LIT-PCBA 全部靶标数或某个经选择的阳性子集代替“有合法三维口袋映射 + 可比较评分 + 可用活性标签 + 可筛全部候选 + 独立标签”的交集。DMS：不能以变异数代替有配对稳定性与功能测量、实验重复和误差模型的实际变异/蛋白数量。

出具联合流程及每一步原始分母：`N0 → N_key → N_label → N_independent → N_eval`，附 join key、重叠清单、被排除比例、正负分布、可用单位数、是否满足最小有效精度。尚未获得文件只报告 `UNKNOWN`，不得填 0；已核实严格为零才写 0。公开数据库 ≠ 数据已经获得；403 ≠ 论文必然无法开展。

## 独立性与来源谱系

必须记录四条边：研究方法的训练输入/先验 → 候选生成/调参 → 测试输入 → 测试参考标准。识别共享资源、回流标注、评估集使用历史和人工挑选。

- 随机拆分如存在同源、同骨架、同病人、同靶标、同实验论文，不能称外部泛化。
- 训练/评估独立不仅看数据集名称，还看原始测量、预训练集、已发表标签、筛选规则和超参数试错。
- 模型内置信息若来源于测试真值或其代理，必须单列 oracle 条件。
- 参考标准只能支持其测量能力内的主张；蛋白/表达/通路代理不能自动升级成真实机制或因果证据。

## 判断证据强度与下一行动

| 观察 | 合理裁决 | 不得推断 |
| --- | --- | --- |
| 可信元数据存在，但在本环境取不到原表 | HOLD_DATA_ACCESS | 世界上没有合格数据 |
| 连接键/标签/谱系未实际核验 | HOLD_NEED_EVIDENCE | 合格交集为零或独立性已通过 |
| 有可靠来源证明所有合法配对交集为零，且无替代可行设计 | STOP 或重定义问题 | 泛化为“此领域无数据” |
| 当前读数无法区分两个机制，但有正交测量可获得 | HOLD_NEED_EVIDENCE | 已证实任何机制不存在 |
| 当前 estimand 数学自相矛盾、无法定义，也无可行重构 | STOP | 其他相关研究问题皆无价值 |

报告有界元数据/样例取得结果、实际执行命令或查询、失败与来源定位；工程障碍不能无限尝试，也不能绕过访问许可。
