# 科研选题：从大规模发现到可开题裁决（V2）

## 使命与底线

目标是在可接受成本内从大量线索中留下**少量真正值得开题的可证伪命题**；允许零个通过。全流程可在一次委托中完成，从机会搜寻、主动组合到对存活选题的全方位开题审计；不要求用户每一关重新发指令。单题也使用同一科学关口。

**不作两种错误裁决：** 没有最近邻全文就宣称创新（假 GO），也不因标题相似、访问 403、预算限制、未读补充材料就断言命题已被覆盖或数据根本不存在（假 STOP）。任何已知缺口必须映射到可审计来源、状态和解锁条件。通过审计不是期刊录用保证。

### 选择任务与授权边界

- **端到端发现（默认适用于“找/拼装/筛选一批课题”）：** 收集多来源线索→去重与组合→分层淘汰→存活者完整 G0–G4 开题审计→给优先级与唯一组合裁决。**不启动模型训练、批量下载或完整试点**，除非用户另有授权。必要时可在既有访问权限内做有界目录、元数据或样例核验。
- **单题/候选组合审计：** 从最近邻研究和数学命题开始，沿同一门槛走到底，必要时提出更窄的新命题，不能仅改标题续命。
- **拒稿/阴性/失败复盘：** 区分已知科学结论、尚缺的新证据、方法失效、发表包装和工程访问问题；重新检索而非继承旧裁决。
- 先冻结范围：目标学科、具体科学/决策问题、资源和计算约束、数据伦理/许可、最大检索与全文预算、最新证据截止日期。用户没有给预算时说明本轮实际上限，不自行承诺搜索 10,000 篇。

## 可扩展的一轮式漏斗

按照 [机会发现与主动组合协议](references/discovery-and-recombination.md) 实施，**候选量可以很大，深度审计必须按证据密度分配**：

1. **多源挖掘并记录分母。** 从异常/失败机制、独立实验资源、成熟方法跨域迁移、未解释现象、实际决策需求五条轨道找线索。记录原始数量、检索式和日期、覆盖范围；搜索结果或语言模型生成的想法都不是科学空白的证明。
2. **语义聚类、硬性浅筛、形成问题簇。** 去除重复标题、同一 estimand 的换数据/换模型、缺科学受益方与不可证伪题。注明剔除的是“待深入线索”还是“有证据证明已覆盖”，不将廉价关键词过滤写成学术 STOP。
3. **证据绑定的主动拼装。** 将可测失败机制 F、候选新机制/方法 M、真实数据 D、独立验证 U、决策或科学增量 C 配对。写出“若无 M 与有 M 会作出哪种不同的可测预测”；核验该组合是否早有直接前作。只有真正产生新 estimand/可识别机制/独立推断或行动增量才称候选研究。
4. **优先淘汰高风险者。** 先做便宜且能改变裁决的最近邻题录与关键全文、理论反例及样本资格核查；不能对成千条线索等量精读。对不确定但有潜力者保留 HOLD/EXPLORE，不伪造详审。
5. **完整深审少量存活者。** 对每个可能 GO 的独立命题完成 G0–G4 所有必填项、强竞争论文 Methods/Results/相关 Supplement、实际数据交集和冻结可否证设计。任一阻断项为 UNKNOWN 时不许 GO。候选可回炉一次，禁止无限“改故事”。
6. **输出组合决策。** 不强行凑出一个 GO 或 Top-3；同时报告发现漏斗分母、逐题证据卡、被淘汰原因、证据仍未知者和资源界限。阈值事先写明，不根据结果回调。

## 硬门槛 G0–G5

门槛详细定义与案例见 [新颖性与问题命题](references/novelty-and-problem-choice.md)、[数学/数据资格](references/identifiability-and-joined-data.md)、[可行性与试点](references/feasibility-and-decision-gates.md)。

| 关口 | **PASS 必备证据** | 触发 FAIL 或阻断的典型情形 |
| --- | --- | --- |
| **G0 问题价值** | 可证伪科学命题；明确受益的推断/实验/决策及最小有意义改变 | 只是换方法排行、无新知识或决策后果 |
| **G1 最近邻新颖性** | 主张级（非题名级）前作对照；最直接竞争研究的 Methods/Results 与相关补充材料；新增且值得知道的 Δ | 相同 estimand、实验和结论已充分覆盖且无独立新证据；全文缺失则 UNKNOWN |
| **G2 定义与可识别性** | 目标量、独立单位、观测映射、识别假设；反例与混杂/替代解释检查；必要时数学或模拟反证 | 多个潜在机制产生同一读出却声称被区分；比较对象没有共同 estimand |
| **G3 真实数据与独立证据** | 实际可获取的字段/版本/许可；**联结键后的联合交集、有效标签与分母**；来源谱系、独立性、泄漏风险；可行处理成本 | 原始母集很大但可分析交集为零；真值进入输入；只是下载受阻则 HOLD_DATA_ACCESS |
| **G4 公平且可否证的冻结试点** | 候选集合与预算、强基线、信息暴露一致性、最小效果、精度/独立单位、结果树、失败即停条件 | 指标与真实决策不一致；零结果不可解释；无法区分最强替代解释 |
| **G5 试点后开题升级** | 实际已执行的有效试点、原始计数和区间、偏离、复现证据、资源成本；编辑层面新增知识 | `pilot=NOT_RUN`、只有预想改善或补充写作，不允许 GO_FULL_STUDY |

每关记录 `PASS / FAIL / UNKNOWN / NOT_TESTED`、证据定位、审查深度、阻断与解锁行动。G0–G4 的 PASS 是 `GO_MINIMAL_PILOT` 的必要条件但非充分期刊保证；G5 PASS 才有资格建议 `GO_FULL_STUDY`。轻量可行性检查是门槛审计，**不是**科学试点已执行。

### 最近邻与判错规则

- 检索原始论文、预印本、后续与交叉领域前作、代码和论文补充材料；区分 `metadata-only / abstract-read / methods-results-read / fulltext-supp-reviewed`。没有完整关键部分时不得写“前人没做”。
- 对每个潜在 GO 写两份证据支持的备忘录：**GO 方最强论证**及**STOP 方最强论证**，并由反向审查独立复核最接近前作。相似术语不是直接覆盖的证明；没有证据的“未覆盖”也不是创新。
- 重点检查：标签置换/零模型与经验 FPR 是否混同第一类错误率；跨工具无法共享 estimand；DMS 稳定性/功能读数能否解耦；虚拟筛选“弃权”是否有固定预算下真实净收益；成熟测量误差、难度分层和可靠性文献是否更直接。
- 不能单独以一篇预印本、一个参考标准、一个纳入子集的样本数判定整个领域/全基准；精确表述适用范围。

### 数据与设计规则

- 真实数据关口区分：`ACCESSIBLE`（能下载）、`JOINABLE`（能按目标键关联）、`ELIGIBLE`（科学上有效且独立）、`POWERED`（有效实验单位与精度足够）。不同数据名字 ≠ 独立，表中对象数 ≠ 交集或独立样本数。
- 用来源图列出训练/基准/调参/标签/外部实验的重合；按人、蛋白家族、分子骨架、靶标、论文或批次分组。任何缺失的关键键或有效标签必须写 `UNKNOWN`；禁止从未下载推断“0 个可用数据”。
- 试点前冻结 estimand、观察单位、Top-B/费用 B、分母、纳排、对照、强朴素与最近邻方法基线、校准/区间、结果树；未在信息公平下比较的命中率、regret、提升率不得宣称有效。

## 一个主裁决，允许零 GO

| 裁决 | 适用条件 |
| --- | --- |
| `EXPLORE_ONLY` | 原始线索或核心命题未定、尚无足够检索；限额补证，不启动实验 |
| `HOLD_NEED_EVIDENCE` | 命题可能成立但最近邻全文、可识别性、实际交集/精度、强基线缺证；列最小解锁要求 |
| `HOLD_DATA_ACCESS` | 数据科学资格尚有希望且有可信元数据，但当前取数/格式/许可访问阻塞 |
| `GO_MINIMAL_PILOT` | G0–G4 均有可核验 PASS、合法数据与冻结试点；`pilot=NOT_RUN` 可成立 |
| `GO_FULL_STUDY` | G0–G5 均有可核验 PASS，试点确实有效执行且结果达到事前标准 |
| `STOP` | 有强证据证明增量已被覆盖、目标不可识别且无法修复、独立证据结构性无效或投入不成比例；附具体证据与再开启条件 |

拒绝 **UNKNOWN→FAIL→STOP** 及 **PLANNED→PASS→GO** 的状态跳跃。单题只给一个主裁决；题库报告可给每题状态和一个**组合层面的**主裁决（`NO_GO_YET / PILOT_CANDIDATES_FOUND / FULL_STUDY_READY`），其含义不能偷换为某一题的科学结论。

## 必需产物与回归

输出所用 [选题档案](assets/topic-dossier-template.md)：搜索分母/检索日志、组合来源与假说、最近邻矩阵与阅读深度、估计量及反例、真实可分析交集、试点冻结方案、双向编辑意见、逐 Gate 证据、成本上限和单一裁决。批量输出候选全表及精审者完整档案；所有实际 `NOT_RUN` 必须醒目标注。可用 [门槛账本样例](assets/gate-ledger-example.csv) 的结构记录机器可查的关口。

修改本 Skill 或做大规模筛选前，运行 [回归与质控协议](references/regression-evaluation.md)；使用 `scripts/validate_gate_ledger.py` 检查状态与 GO 合法性，再由人/模型基于原文检验真实性（脚本**不能**证明科学新颖性）。历史假 GO 和假 STOP 都必须能被发现。

需要时联动 `retrieve-and-match-references`、`critically-read-literature`、`guide-research-methods-statistics`；仅在过 G5 后考虑写稿技能。有关外部框架来源见 [来源与改造说明](references/sources-and-adaptations.md)。联动调用不等于已读、已下载或已运行。
