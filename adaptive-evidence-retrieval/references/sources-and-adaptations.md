# External inspiration and boundaries

Independent synthesis, not verbatim incorporation. Check original repositories' current licenses before importing any code or templates. Attribution does not imply endorsement.

- [ramit-mitra/deep-research-skill](https://github.com/ramit-mitra/deep-research-skill): adaptive iterative search, investigation passes and explicit stopping.
- [Stanford STORM](https://github.com/stanford-oval/storm): multi-perspective questioning and outline-guided information discovery; a search heuristic, not proof.
- [K-Dense scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills): domain research lookup and evidence-oriented workflows.
- [dashhuang/deep-research-skill](https://github.com/dashhuang/deep-research-skill): technical counterevidence and failure-mode searches.
- Existing local modules `research-topic-selection` and `retrieve-and-match-references`: scientific gate and citation-depth requirements.

All contents in this module are newly authored operating rules. No third-party code or raw templates are redistributed.
