# P01—P24作图检查

逐panel填状态（通过/部分通过/不通过/不适用/待核）、依据、位置、修正与复核结果；不总分。

| ID | 检查内容 |
| --- | --- |
| P01 | 问题、读者应看到的信息和图型理由明确。 |
| P02 | 图型符合原始/汇总数据条件，无伪样本。 |
| P03 | 来源、版本、哈希、数值与冻结结果一致。 |
| P04 | 独立单位、配对/聚类、ID和n明确。 |
| P05 | 缺失、排除、删失、分母不混淆。 |
| P06 | CI/SD/SE/IQR/LoA定义和上下界正确。 |
| P07 | 效应、区间和基线完整，未夸大意义。 |
| P08 | 完整箱线须/端帽、离群点与KDE条件。 |
| P09 | 坐标单位、范围、参考和log尺度合理。 |
| P10 | 排序、bins、转换、平滑、归一化与抖动可追溯。 |
| P11 | 同组编码和可比panel尺度一致。 |
| P12 | 色图语义、缺失专色、冗余编码和灰度检查。 |
| P13 | 单panel独立，无组图或隐藏独立问题。 |
| P14 | 最终尺寸、字号、线宽可读，规则来源明确。 |
| P15 | 实际字体/覆盖核查，无缺字或静默替代。 |
| P16 | 所有标题、标签、刻度、offset、色标/注释未裁剪。 |
| P17 | 文字不重叠，引导线归属明确。 |
| P18 | 图例未遮挡点、线、数字、区间及关键内容。 |
| P19 | 实际TIFF为RGB/LZW、双向800dpi，像素/尺寸相符。 |
| P20 | PDF单页正确尺寸、线/字矢量及嵌入字体，混合内容说明。 |
| P21 | 独立代码、参数、依赖、来源及重运行命令齐全。 |
| P22 | 最新TIFF及PDF均逐panel实际查看。 |
| P23 | 修正后重导出，最新预览对应，无未说明例外。 |
| P24 | 命名、图注/正文对应、待确认项和期刊版本清楚，私有数据未进公开skill。 |
