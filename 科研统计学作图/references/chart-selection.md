# 根据表达目的选择图型

先确定问题、变量、独立单位、配对/聚类和可用数据，再选图。以下目录不要求将每个结果画遍。

| 表达任务 | 候选 | 必须核查 | 常见误用 |
| --- | --- | --- | --- |
| 小样本连续值 | strip/dot | 全部点、组别、n | 均值柱隐藏分布 |
| 多组分布 | box+原始点 | IQR、完整须/端帽、须定义 | 把须叫CI、隐藏离群 |
| 密度形态 | violin/raincloud+点 | KDE带宽、样本量、支持域 | 小样本假光滑、越过变量边界 |
| 两次配对变化 | paired slope/dumbbell | 真实ID、条件方向、缺失配对 | 强行配对独立样本 |
| 配对效应 | 差值分布；另一个effect/CI panel | 差值方向、患者单位、已核CI | 两组箱体掩盖个体变化 |
| 多条件效应 | dot+CI/forest/caterpillar | 估计量、区间、无效参考值 | 仅用CI重叠判显著 |
| OR/RR/HR | log-scale forest | 正值区间、参考1、调整模型 | 用0作无效值 |
| 单值频率 | histogram | 共同bins、计数/密度、缺失 | 调bins制造峰形 |
| 整体分布/尾部 | ECDF/complementary ECDF | 分母、阶梯、尾部支持 | 计数当概率 |
| 双连续关系 | scatter | 单位、分组、分析单位 | 把相关当因果、乱连线 |
| 密集点云 | hexbin/二维density | 分箱/带宽、色标单位 | 选择性抽点 |
| 方法一致性 | Bland–Altman | 差值/均值、bias/LoA、重复结构 | 相关代替一致性 |
| 时间/有序趋势 | line/step+已核CI带 | 顺序、缺失断线、个体vs汇总 | 自动平均重复测量 |
| 诊断区分 | ROC；低患病率另看PR | 标准、阈值、AUC/区间、患病率 | 检出率当准确性 |
| 概率可靠性 | calibration | 分箱n、45°参考、评估集 | 在训练集认证泛化 |
| 临床阈值收益 | decision curve | 阈值、净收益、treat-all/none | 无行动含义机械DCA |
| 时间事件 | KM/cumulative incidence | 风险人数、删失、时间零点、竞争风险 | 用1−KM估竞争风险发生率 |
| 分类错误 | confusion matrix | 计数、归一化方向、分母 | 百分比隐藏少数类别n |
| 矩阵/模型×条件 | heatmap | 色标/统一范围、缺失专色 | 每panel各自调色 |
| 正负变化矩阵 | centered/diverging heatmap | 有意义中心、范围 | 无中心也用红蓝 |
| 排名/贡献分解 | ranked dot/waterfall | 排序、基线、是否可加和 | 无区间排名、硬拆非加和量 |
| 类别计数/组成 | bar/stacked bar | 零基线、分母、完整类别 | 连续值用均值柱 |
| 集合交集 | UpSet | 基数、交集定义 | 多集合仍强画Venn |
| 效应与多重检验 | volcano/Manhattan | 完整背景、调整P、预设阈值 | 只留“故事”点 |
| 样本流/去向 | flow/alluvial | 人数守恒、排除、重复单位 | 流宽不对应人数 |
| 失败模式 | category dot/bar；代表例另panel | 完整分母、类别定义 | 极端例冒充总体 |

高级图型使用核实的专用库/原论文实现，另核公式与统计流程。需多个研究问题时拆成独立panel；KM风险表、热图色标可作同一对象的辅助轴。

选图顺序：原始观测是否支持分布/配对→问题属于哪行→更简单的点/区间是否足够→是否遗漏配对、简单基线或参考标准→所需新统计量是否已获分析授权。没有原始值时转汇总点/区间，不能造分布。
