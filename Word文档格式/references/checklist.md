# Word格式20项自查

逐项填状态、位置、参数/规则来源、证据、修正动作和复核状态；不以结构检查代替视觉检查。

| ID | 检查项 |
| --- | --- |
| F01 | 最终参数有用户、官方、模板或内部默认来源，冲突明确处理。 |
| F02 | 原件保留，副本版本清楚，适用范围明确。 |
| F03 | 正文及标题、列表、图注、表注、文献等角色分类正确。 |
| F04 | 正文两端对齐，无异常字距或与源格式冲突的分散对齐。 |
| F05 | 正文首行按语言/要求缩进，非手打空格/Tab，特殊段落不误缩。 |
| F06 | 倍数行距和段前后间距一致，固定行高未截断公式/上下标。 |
| F07 | 字体、字号、颜色按规则，符号、斜体、上下标与必要强调保留。 |
| F08 | 标题层级及与下段连接正确，未改变标题文字/标点。 |
| F09 | 页面显示表顶、完整表头块下与最终底线正确，无残余竖线、网格、对角线、双线或底色；非打印网格不误判。 |
| F10 | 多级/合并表头边界正确，跨表头边界合并等复杂情况已人工处理，辅助线与例外有依据。 |
| F11 | 表格列宽、对齐、精度、内边距和行高可读且不截字。 |
| F12 | 跨页完整表头重复、数据接续正确，正常行不误拆；无keep-next串联造成的大量留白，超长行与表尾人工复核。 |
| F13 | 表题、表注、图注和相邻对象关系清楚，无孤立说明。 |
| F14 | 图像比例、分辨率和公式呈现保留，未替换为错误内容。 |
| F15 | 文献、列表与引文序号结构保留，悬挂/编号格式正确。 |
| F16 | 页面、边距、分节及横向页正确，未批量覆盖特殊布局。 |
| F17 | 页码、行号、页眉页脚及匿名要求按适用性处理。 |
| F18 | 文字、数字、表格合并、域/链接、公式与图像关系核对通过，允许空白改动另记。 |
| F19 | 批注与修订状态保留，未静默接受、删除或匿名化。 |
| F20 | 最新DOCX在独立目录渲染且所有页实际查看，三线表边界与跨页验收通过，无缺字、截断、重叠、孤悬或分页缺陷；不能用XML或文本提取替代。 |
