# 学术Word格式规则

## 默认与覆盖

配置资产是内部默认，可直接覆盖；当前期刊格式需要官方核查。语言默认从文本及用户要求确定。已有模板/期刊标题样式优先；全文两端对齐指正文，不包括所有对象。

| 对象 | 默认 | 核查要点 |
| --- | --- | --- |
| 正文 | 12pt；中文宋体、英文Times New Roman；黑色 | 字体可用性和实际渲染；不覆盖Symbol/数学字体 |
| 正文段落 | 两端对齐；1.5倍；段前后0pt | 期刊可能要求双倍，按已核实要求覆盖 |
| 中文首行 | 2字符（w:firstLineChars=200），同时给字体对应的长度回退 | 首行缩进不是在文本前插两个空格；回退不能当实际字符测量 |
| 英文首行 | 0.5英寸，清除遗留字符单位缩进 | 默认偏好，不是英文期刊通用标准 |
| 标题 | 保持现有字号体系或清晰层级，首行不缩进 | 与下段连接，不创建装饰线 |
| 图表说明 | 按期刊摆放，默认左对齐、无正文首缩、单倍至1.15倍 | 长图注可按明确要求两端对齐 |
| 参考文献 | 按期刊格式，必要时悬挂缩进 | 不更改引文内容、序号、域和链接 |
| 表格文字 | 默认10—12pt、无首缩、单倍至1.15倍 | 不为塞满页面极端缩小字号 |
| 三线表 | 顶/底1pt，表头下0.5pt；无竖线/内部网格/底色 | 线宽可覆盖，实际边界以多层表头为准 |
| 页面 | 编辑时保留尺寸、边距与分节 | 新建遵循环境文档工具默认，指定/期刊要求覆盖 |

## 首行缩进与空白

区分首行缩进（横向）、段前/后间距（纵向）和行距。先清点前导空格/Tab，只有纯视觉占位才清除，保留有含义的代码/公式对齐。避免同时保留字符缩进和过大的长度缩进冲突；中文字符缩进通过Word属性实现，其他渲染器可能使用长度回退，须看实际结果。

## 三线表

优先可编辑表，不用图片假装表格。最上方横线、整个表头块下方横线、表底横线构成三线；多级表头可能有跨列合并。跨页重复表头不等于增加独立数据行。既有条件样式、单元格边框和底色都可能残留，必须显式处理并渲染确认。

辅助函数仅应用到已确认的表，表头行数必须正确传入。对纵向合并跨越表头边界、嵌套表格、特殊分组线、超长单元格等复杂情况人工处理和记录例外，不声称自动函数已解决。列宽、数值小数对齐、横向页面和图像布局由执行者针对内容调整。

## 可追溯性

指定字体必须在实际渲染环境可用。缺少中文字体时，即使PDF能够提取中文也可能在页面上不可见；不能据文字提取判定字体通过。先检测字体，使用已安装且覆盖相应字符的替代字体并向用户说明，或标中文视觉核验未完成，不悄悄认证。测试域/书签也必须有效，渲染器更新域造成的引用错误应单独定位，不能把域删掉来掩盖错误。

记录规则来源（用户/官方/模板/内部默认），保留原件和副本。格式操作不得静默接受修订或改变内容；内容校对是另一任务。交付前检查最新渲染所有页，不按抽样页认证整个文件。
