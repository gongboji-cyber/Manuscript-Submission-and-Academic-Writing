# 证据和语义完整性

## 最小图元素台账

画图前为每个主要元素记录：

| 字段 | 内容 |
| --- | --- |
| element_id | 稳定节点/边ID，修改标签后不改ID |
| type | 数据、动作、判定、输出、回退、组、注释 |
| exact_label | 图中文字与单位 |
| relation | 起点→终点，顺序/数据流/条件/时间/因果假设 |
| evidence | 文稿段落、原始台账列+版本、代码函数/提交、DOI页码，或“尚无证据/拟议” |
| status | verified / conditional / planned / unverified |
| reviewer_note | 分母、版本、时间零点、不确定性、对应图注 |

**图上的美学确定性不等于科学确定性**。若证据冲突，保留冲突与待核状态；禁止悄悄选最吸引人的路径。

## 不同研究的特殊校验

### CONSORT / PRISMA / 患者纳排

- 先核对目标指南与实际研究设计、当前版本；从官方模板提取必备信息，而不是猜一个“官方通用图”。
- 明确人、就诊、样本、文献记录、全文报告、试验、观察窗的独立单位。不同单位的数量不可相减。
- 每一父节点与子节点及排除数之间写出加和核对；理由可能重叠时不要擅称互斥，必要时拆成并列附注。
- 追踪首次筛查、去重、资格评估、纳入、分配、随访、缺失、主要分析，按实际设计保留/删除阶段。
- 同一患者可以有多个分析样本时单独标注，不能画成“样本数=患者数”。
- 未提供台账时用“待核”而非虚构的 `n`。用模拟数值演示须醒目标注 SYNTHETIC。

### 技术路线/实验流程

- 分清假设、准备、实验、评价、失败转向、阶段产出；带箭头的阶段需存在逻辑或时间依赖。
- 已执行和计划中使用不同填充/边框/标签，并在图例注明；不能用一张漂亮的既成路线图伪造已经完成。
- 如果循环优化没有预先定义停止规则，标“迭代设计”而非暗示获得理想结果。

### 计算管线与模型架构

- 从实际运行的代码路径、参数配置、数据分割与版本恢复拓扑；类名、目录结构和论文概述不能替代真实调用。
- 区分训练集、验证集、外部测试、预处理拟合对象、模型选择信息；不得画出不存在的盲测隔离。
- 标清GT/人工标注的访问点；GT参与裁剪/筛选时不可用普通“preprocessing”掩盖。
- 残差、拼接、融合、跨模态连接、复用模块不能合并成错误的单一箭头。对不确定结构标待核。

### 因果/临床机制/诊断决策

- 因果DAG是领域假设的编码，不是关联矩阵的可视化。未证实的机制边用明确的假设符号和文本。
- 临床诊断算法只能忠实描述其来源或用户给定方案；避免将科研探索图伪装成可执行临床指南。
- 阈值写单位、方向、依据和适用人群；未验证性能不能写“准确”“可靠”等结果性判断。

## 数值核对最小集

1. 分母、百分比、时间窗、阈值和置信区间必须与冻结结果一致。
2. 分支总和不一致时记录缺失/重叠/不同单位，不用装饰性箭头掩盖。
3. 图注、主文、补充、表格的节点名、简称、数据版本保持一致。
4. 显示“验证”“外部测试”“随机化”等术语须有对应实际步骤；“planned”不等于“performed”。
5. 正式流程指南应以适用的官方版本为准：CONSORT、PRISMA、STROBE等不是任意研究通用的认证图标。

## 必须暂停的情况

关键箭头关系不成立、纳排数无法确认、流程图暴露未授权数据、模型拓扑与代码相冲突：停止发表级定稿，继续完成标注待核的结构草案和待补证据清单。
