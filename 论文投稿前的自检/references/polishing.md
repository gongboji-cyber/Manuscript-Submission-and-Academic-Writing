# 润色与复核

## 修改次序

1. 修确定的内部矛盾，未知数值/事实记录冲突，不猜。
2. 校准因果、机制、普遍优越性和临床获益至证据范围。
3. 改章节任务与段落推理，不用过渡词掩盖缺证据。
4. 改语法、清晰度、术语、缩写和冗余，保持作者声音和原语言。
5. 复核修改后的数字、含义及跨章节一致性。

## 事实边界

- 保留估计、样本量、区间、P值、符号、单位与方向；有可靠依据才纠错，改数值逐项注明来源。
- 不为有力语气删除may、associated with、in this dataset、exploratory等边界。
- 不补未知注册、审批、盲法、预设、开放或作者同意。
- 单数据集验证不改成普遍外部验证；公开模型拼装不改称新算法。
- 无显著差异不改为等效，除非设计与适当等效分析支持。
- 静态代码或某版本缺陷不推及所有实现及既有论文。
- 不通过改标签、剔除不利样本或事后阈值制造更好结果；必要分析另列动作。

默认保留原件、创建命名清楚的副本；按用户要求保留/生成修订，用对应文件技能避免丢失表格、公式、批注、脚注和引文。完整稿件交付可编辑副本与报告，并按环境保存。图须查看最终渲染的截字、重叠、字号、图例、颜色、间距和单位，DPI不代替视觉检查。重绘服从范围并保留源数据与统计含义，列出未验证项。
