# 投稿前检查清单

使用原创内部诊断项，不称为经验证量表或正式报告指南。默认级别是检查顺序，按实际影响定问题级别。每项填状态、位置、依据和动作；区分报告缺项、无法核实与已证实缺陷。

## 目录

- T 标题；A 摘要；I 引言；M 方法；R 结果；D 讨论；C 结论
- F 图表与图注；X 跨章节；S 补充与复现；J 投稿、引文与声明

## T 标题

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| T01 | P1 | 主题、对象和任务明确；不暗示未研究的疾病、技术或结局。 |
| T02 | P0 | 因果、机制、普遍优越性与临床获益措辞有设计和结果支持，限定条件未抹去。 |
| T03 | P2 | 简洁可读，缩写、类型标记与长度服从核实过的期刊要求。 |

## A 摘要

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| A01 | P1 | 背景迅速说明具体问题和重要性，不以空泛领域宣传替代缺口。 |
| A02 | P1 | 目的对应正文主要问题，预设、探索与事后问题不混淆。 |
| A03 | P1 | 有必要的设计、来源、对象、规模、主要比较和结局信息。 |
| A04 | P0 | 主要效应、单位、分母和不确定性准确，与正文一致。 |
| A05 | P0 | 保留改变结论的失败、阴性发现及条件，不选择性压缩。 |
| A06 | P0 | 结论受结果支持；技术性能不直接转为患者获益，非显著不等于等效。 |
| A07 | P1 | 结构、字数、缩写、引文及必要注册信息符合当前类型要求。 |

## I 引言

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| I01 | P2 | 背景与实际贡献匹配，避免无关教科书式铺陈。 |
| I02 | P1 | 对象、任务、条件和问题明确，从背景收敛到问题有逻辑依据。 |
| I03 | P1 | 选择对象有科学或应用理由，不只因为热门。 |
| I04 | P1 | 覆盖最接近的代表工作和进展，按策略/问题综合而非堆作者。 |
| I05 | P0 | 对前人能力和限制的描述有原始来源支持，未读来源不判事实通过。 |
| I06 | P0 | 缺口具体可检验，区分未研究、已有局限及已有不一致，不虚构空白。 |
| I07 | P1 | 缺口后果和意义有合理链条，不制造无依据临床危机。 |
| I08 | P0 | 目的与设计回应所述缺口，不只测一个容易获得的替代问题。 |
| I09 | P1 | 相对最接近工作准确说明贡献，新数据、新验证和新算法不互换。 |
| I10 | P1 | 说明范围与思路；若预告发现，其条件和强度与摘要、结果一致。 |
| I11 | P2 | 过渡体现推理，篇幅适配类型，不强制句式、句数或固定段落模型。 |

## M 方法

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| M01 | P0 | 设计能裁决主要问题，对象、比较、目标估计和主要结局明确对应。 |
| M02 | P1 | 来源、时间/版本、纳排、筛选和排除原因透明，可核对最终样本。 |
| M03 | P0 | 独立与分析单位分清，重复患者、图像、切片、化合物等层级正确处理。 |
| M04 | P0 | 参考标准形成及误差充分说明，不存在结局与输入/分组循环定义。 |
| M05 | P0 | 比较公平或差异有理由，输入、提示、预处理、调参与计算预算可核对。 |
| M06 | P0 | 训练/调参/测试、身份/来源重叠与拟合范围清楚，无已证实相关泄漏。 |
| M07 | P1 | 参数、阈值、单位、版本、依赖与顺序足以复现，不以仓库URL替代方法。 |
| M08 | P1 | 主要/次要结局、阈值、指标、方向、聚合和失败计分定义明确。 |
| M09 | P0 | 统计方法匹配配对、聚类、重复测量和目标估计，效应与区间方法明确。 |
| M10 | P1 | 缺失、失败、异常值与剔除透明，分母变化能对应结果。 |
| M11 | P1 | 规模/精度依据、多重比较和分析选择适配研究，事后不伪装预设。 |
| M12 | P0 | 关键解释有必要对照、消融或敏感性分析，未排除解释被保留。 |
| M13 | P1 | 随机、盲法、混杂控制、伦理/同意/许可按适用性报告。 |

## R 结果

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| R01 | P0 | 纳入、排除、失败、缺失与最终分母可对账，计数单位明确。 |
| R02 | P1 | 先回答主要问题，证据逻辑清晰，不被漂亮的次要结果替代。 |
| R03 | P0 | 效应、方向、单位和不确定性准确，不只报告P值或形容词。 |
| R04 | P1 | 必要分布、个体/亚组/场景差异可见，汇总不掩盖关键失败。 |
| R05 | P0 | 不利、失败和阴性结果完整，不无解释地移出分母或删除条件。 |
| R06 | P1 | 探索、次要、事后与敏感性分析标清，不挑最佳设置作为验证。 |
| R07 | P0 | 文本、图表、补充和源数据一致，冲突记录而非猜测替换。 |
| R08 | P0 | 相关不写成因果，不显著不写成等效，点估计领先不写成确定优势。 |
| R09 | P2 | 结果句可追溯图表，保留必要数字，推测放讨论或标为假设。 |

## D 讨论

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| D01 | P1 | 开头回答问题及边界，不重复背景或逐项复述结果。 |
| D02 | P0 | 观察、解释、机制推测和建议分层，核心主张有可追溯依据。 |
| D03 | P1 | 比较文献时交代对象、任务、条件和指标，不用不可比数字称优。 |
| D04 | P0 | 认真处理相关替代解释，一次敏感性分析不声称排除所有偏倚。 |
| D05 | P1 | 相对最接近工作说明新增知识、边界或能力，不用首次代替贡献。 |
| D06 | P1 | 局限说明影响哪个主张、可能方向或未知，不只是套话罗列。 |
| D07 | P0 | 应用、迁移和临床意义受验证范围限制，未验证获益明确待验证。 |
| D08 | P1 | 后续研究针对具体未决解释或条件，给可裁决设计。 |
| D09 | P2 | 批评指向问题和证据，准确公允，减少宣传、防御和重复。 |

## C 结论或讨论末段

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| C01 | P1 | 回答原问题，说明现在能确认的新增知识。 |
| C02 | P0 | 保留决定结论成立的对象、场景、条件与不确定性。 |
| C03 | P0 | 无正文未支持的新结果、机制、因果或应用承诺。 |
| C04 | P1 | 建议强度与证据相称，区分立即行动与待验证方案。 |

## F 图表与图注

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| F01 | P1 | 每张图表有明确证据任务，多面板有论证关系而非装饰。 |
| F02 | P0 | 图形匹配配对、时间、分布与层级结构，未改变分析含义。 |
| F03 | P1 | 必要样本量、观测值、分布和失败信息可见，不只展示有利均值。 |
| F04 | P0 | 截轴、对数、色阶、排序和选择性展示不造成未披露误导。 |
| F05 | P0 | SD/SE/CI、统计符号、计数单位和比较对象定义准确。 |
| F06 | P1 | 图注交代对象、条件、单位、符号、缩写和必要统计信息。 |
| F07 | P1 | 表头、精度、缺失/失败与脚注明确，数据不冲突。 |
| F08 | P2 | 实际查看最终尺寸，无截字、重叠、面板拥挤或不可辨颜色。 |
| F09 | P1 | 源数据及生成过程可追溯，DPI、格式、尺寸按期刊要求实测。 |

## S 补充与可复现

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| S01 | P1 | 核心证据正文可见，补充不隐藏改变结论的失败。 |
| S02 | P1 | 补充编号、链接、方法和数值同步，无旧版本残留。 |

| J02 | P1 | 匿名要求已核，稿件、补充、文件名与元数据按要求处理，不默认盲审。 |
| J03 | P0 | 关键引文支持附近主张且元数据准确，二手引用/未读范围不隐瞒。 |

| J06 | P1 | 作者、贡献、冲突、资助、致谢与AI使用声明按事实和要求一致。 |
