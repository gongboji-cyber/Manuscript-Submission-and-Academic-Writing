# 适用范围与裁决

## 文章类型

| 类型 | 调整 |
| --- | --- |
| 原创研究 | 按设计覆盖模块，不机械要求独立Conclusion。 |
| Research letter | 保留科学有效性检查，接受合并或未标标题的IMRAD，按官方限制控制篇幅。 |
| Correspondence | 核查评论对象、引文、批评依据和范围；没有自己的研究时方法/结果项不适用，但原文不可核实时仍标未知。 |
| 方法学/代码审计 | 锁定版本和路径，区分静态可达、实际触发、数量影响、因果定位与外推；一个实现问题不等于整个领域失效。 |
| 观察性研究 | 关注时间顺序、选择、混杂、缺失、重复患者与测量，关联不改为因果。 |
| 干预/诊断/预测研究 | 分别关注分配与分析人群、参考标准及验证偏倚、训练测试隔离和校准；用适用正式报告指南。 |
| 系统综述 | 另查检索日期/策略、筛选、重复队列、偏倚与合成；基础清单不单独证明综述报告合规。 |
| 仅段落/章节 | 限定范围，跨章无法核实或范围外；不虚构全文结论。 |

## 缺材料与错误

- “无泄漏”但没有划分材料：报告作者自述、标无法核实，不断言已发生泄漏。
- 完全未写区间计算方法：报告缺项不通过，计算正确性仍无法核实。
- 正文90人、图表100人：内部矛盾不通过，不猜哪个是真值。
- 未提供源数据但内部一致：可做跨材料核对，不能声称独立重算；不自动阻断。
- 声称首次但未核最接近工作：新颖性待核；优先定位实际增量，不保留无依据绝对断言。

## 裁决

- 暂缓提交：已证实P0影响核心结论，或具体关键矛盾/未知使核心主张不能裁决；列解除条件，继续其他授权工作。
- 需修订：尚未发现影响核心结论的已证实缺陷，但报告、措辞、复现或合规有缺项；部分主张需限定。
- 本次范围内可提交：范围内核查完成，核心主张有依据，无开放阻断项；说明实际核验深度，不保证真实性、录用或未审部分。
- 仅完成语言润色：材料/任务仅支持文本修改；不认证整个投稿包。

期刊未知不阻断科学自查；写“科学与文字范围内完成；期刊特定要求未核验”。只收到一句话时给完整改句、含义变化与必要待核事实，不输出90行空表。完整自查须逐项覆盖清单与主张表。

需要核实官方指南、期刊要求和文献时读取官方或原始来源，记录日期与阅读范围；失败标未知，继续内部核查。
