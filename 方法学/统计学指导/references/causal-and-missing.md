# 因果识别、偏倚与缺失

使用作者教材入口 S01 和 ICH S04 建立概念；缺失方案参考 S02 与 S15。以下为本模块的实施原则，具体复杂情形必须补读针对原文。

## 因果路线

1. 写目标试验：人群、资格、处理策略、分配、随访起止、结局、因果对比和分析计划。对齐资格、分配与 time zero；防止按未来治疗或未来存活分组造成 immortal-time bias。
2. 用领域知识画时序和 DAG，标识共同原因、碰撞点、中介、结局后变量及选择节点。不以“相关/显著”决定混杂；不自动调整所有可用变量。
3. 说明一致性、条件可交换性、positivity 和测量假设，以及哪些无法从数据检验。随机化、匹配、倾向评分、IPW、“双稳健”和机器学习均不能自动解决未测混杂、选择偏倚或错误 time zero。
4. 对权重/匹配报告重叠、平衡、极端权重、有效样本量、丢弃比例与目标人群改变。截尾阈值事先有理由并做敏感性，不能只展示平衡改善。
5. 处理中间事件、时间变化暴露/混杂时按目标量选择 g-methods 等适用策略，先读专门来源再实现。横断面中介模型不凭显著间接路径宣称机制。
6. 若关键识别假设不可信，改为关联、明确探索性，或要求新设计；数学复杂度不能补识别缺口。

## 缺失路线

- 按变量、组、时间、cluster 记录缺失数量、原因和联合模式；区分未检测、测不到、退出、结构不适用和真实零。不把所有缺失编码成0。
- MAR/MNAR 是机制假设，不能由缺失率低或 MCAR 检验不显著证明 MAR。缺失可能影响代表性、偏倚与精度，不能靠把计划样本量除以保留比例彻底解决。
- Complete-case 对所估目标量需有理由；若允许，逐项报告损失的人/对/cluster、保留人群及敏感性，不能静默改变分母。部分情形在非 MCAR 下可成立，不能笼统声称只要非 MCAR 就必然偏倚。
- MI 明确插补变量、类型、时序、辅助信息、交互/非线性、层级结构、次数与蒙特卡洛稳定性；与分析模型相容，按规则合并不确定性并检查分布/收敛。不能用单次均值插补加普通 SE 冒充 MI。
- 推断分析中结局可作为合理插补预测变量，取决于缺失与模型；预测验证中不能用测试结局插补预测变量或让测试数据参与拟合。两种情境不能机械套一个规则。
- MNAR 用领域可解释参数/模式混合/选择模型等情景分析；参数来源、合理范围及 tipping point 明示，不宣称已从观测数据确定 MNAR。
- 生存删失、死亡截断、竞争事件、中间事件策略分别处理，不混称普通缺失。行政删失也需符合时间定义和适用独立删失假设。

区分“观测到异常”“有证据支持机制”“尚不可识别”。数据审计脚本只能定位数据模式，不能识别混杂、MAR/MNAR 或证明因果。
