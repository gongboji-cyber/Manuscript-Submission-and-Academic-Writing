# 从问题到设计

先定义目标量，再使用下表分流。所有路线均需说明来源人群、纳排、独立单位、测量时点、权重、缺失与不确定性；框架依据见 S01–S13，具体落实为本模块原创工作流程。

| 问题 | 设计与关键审计 | 结果及报告框架 |
|---|---|---|
| 描述负担/分布 | 抽样与覆盖、分母、重复记录、调查权重与设计效应 | 比例/率/分布及精度；描述不能自动推广所有人群 |
| 关联 | 横断面/队列/病例对照；变量时序、测量误差和选择机制 | 条件关联；STROBE；病例对照需注意不能由抽样病例比例直接估总体风险 |
| 随机试验因果 | 随机序列、隐藏、盲法、干预实施、分配单位、失访、中间事件 | 事先 estimand、效应和区间；CONSORT 2025，方案 SPIRIT 2025，适用扩展另查 |
| 观察性因果 | 明确目标试验、时间零点、处理策略、随访、DAG/识别、可交换性、positivity、一致性 | 效应仅在可辩护假设下；不因“调整很多变量”升级为因果 |
| 诊断准确性 | 代表性样本、独立参考标准、阈值、盲法、验证流程、多靶点依赖 | 指标/区间、失败和不确定结果；STARD 2015，AI 查 STARD-AI 2025；评审用 QUADAS-3 |
| 预测 | 预测时点可用变量、事件率、开发/评价分离、校准、内部与外部验证 | TRIPOD+AI 2024；评价质量/偏倚/适用性用 PROBAST+AI 2025 |
| 系统综述/合并 | 预先 PICO、检索、重复筛查/提取、同一队列多报告去重、研究内相关性 | PRISMA 2020；另选设计对应偏倚工具；异质性不能靠固定效应消失 |
| 方法/计算基准 | 公平输入与资源、任务独立性、协议冻结、基线、失败分母 | 任务条件下表现；不能自动转成临床效用或普遍优越 |

## 目标量卡

写出“在【人群】、【时间窗】中，比较【A/B条件】，估计【结局定义】的【汇总量】，以【单位/权重】为目标”。试验依 ICH E9(R1) 分别定义人群、处理条件、变量/结局、中间事件处理、总体汇总。治疗停止/救援/死亡与缺失观测是不同概念；死亡后不存在的结局不能不加说明当普通 MAR 缺失。

例如同一患者多个靶点：患者等权均值与靶点等权均值回答不同问题。病例级 bootstrap 也不能决定哪个更正确。先声明总体目标，再决定抽样层级和每次重复的估计函数。配对比较保留同一人两种方法的对应关系；不能把两个配对样本当作独立组。

## 样本量与可行性

依据目标效应/最小有意义差异或区间宽度，说明变异、基线率、alpha/多重性、目标 power/精度、失访、聚类大小和 ICC 的来源及范围。预测模型结合候选参数数量（含样条、交互）、结局频率、预期解释度、收缩与精度；Riley 等 S14 不支持一个固定 EPV 通用阈值。外部验证需另评估评价指标精度，不沿用开发样本量规则。

不凭总行数或“超过30/100/10 EPV”宣布样本充分，不默认中等效应。做参数敏感性表；缺乏先验参数时先导数据、外部证据或精度预算比随意给值更合理。结果已知后不用 observed power 解释 P 值；区间反映当前精度。样本不足可缩小目标、降低模型复杂度、补数据或明确探索性，不能靠复杂模型制造信息。
