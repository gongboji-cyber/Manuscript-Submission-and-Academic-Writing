# 方法选择与失败诊断

方法遵从目标量、依赖结构与测量机制。下表是决策起点，不是自动检验菜单。依据 S02–S05/S14–S16/S18–S19；专业路径在实际使用时再读相应原始方法和软件文档。

| 目标/结构 | 可考虑的方法 | 必查假设、诊断与边界 |
|---|---|---|
| 独立两组均值差 | 预先指定 Welch 或有理由的方差模型、回归调整；设计支持时重抽样 | 单位独立、极端值/重尾、样本精度；不能先做 Levene 再自动选方法 |
| 配对连续结局 | 配对差估计、配对模型；独立患者 cluster bootstrap | 检查差值与缺失对；平均差不是秩检验目标 |
| 秩/顺序比较 | Mann–Whitney、Wilcoxon、ordinal 模型，按目标量选择 | 不自动解释为中位数差；位置移位/对称等额外假设需说明 |
| 二分类/配对二分类 | 风险差/比/OR对应模型与区间；独立配对可用 McNemar | 分母/稀疏和分离；OR 不等于 RR，聚类需额外处理 |
| 计数/率 | Poisson、负二项、合适的零膨胀/两部分模型 | 暴露时间 offset、过度离散、生成零机制；不因有零就加零膨胀 |
| 连续/非线性回归 | 线性模型、预先样条、稳健方差或适用广义模型 | 条件残差、功能形式、影响点、支持范围；X 正态不是线性回归必要条件 |
| 重复/嵌套/交叉测量 | mixed model、GEE、层级 bootstrap 或设计模型 | 条件/边际目标不同；cluster 数量、随机效应可识别、小样本方差、交叉依赖 |
| 生存/竞争风险 | 生存概率、RMST、Cox、原因特异/亚分布模型按问题选 | 时间零点、删失、PH、预定 RMST 截止；竞争事件存在时 1−KM 不能直接解释为累计发生率；HR 不是绝对风险 |
| 亚组/交互 | 预设交互、标准化效应及区间 | “一组显著一组不显著”不是组间差异证据；多重性/低精度 |
| 等效/非劣 | 事前可辩护界值及设计、对应区间/检验 | P>0.05 不证明等效；事后按结果挑 margin 无效 |
| Bayesian | 有来源的先验、似然与决策目标；后验检验 | 先验/模型敏感性、收敛与有效样本量；可信区间不叫 CI，MCMC 成功不证明模型正确 |
| Meta-analysis | 目标明确的合并、研究内协方差、异质性/预测区间 | 重复队列、稀少研究、选择偏倚；按问题查Cochrane适用章节及版本(S18)，不自动合并不可比效应 |

## 统一诊断

- 保留单位和效应方向；报告有效独立单位数、每项分母、估计值和区间。SD、SE、CI 三者不可互换。
- 正态性检验 P 值只是一项诊断，不是均值方法→秩方法的开关。结合设计、目标量、残差/差值、极端值影响、稳健性与样本精度；改变方法可能改变目标量。
- 不默认二分连续变量、以中位数切组、单变量 P 筛协变量或 stepwise 为主方案；保留非线性、预先知识和过拟合控制。标准化系数与原尺度效应分开解释。
- 对拟合记录缺失剔除、分析样本、参数数、收敛、分离、边界估计、极端权重、影响点。不能只检查返回码，也不能静默删掉不收敛重复。AIC/likelihood 比较需同样数据和可比较似然，不能跨不同结局/纳排机械排名。
- 指定多重检验“族”、主次与 FWER/FDR 目标；不能把所有 P 无差别塞入 FDR，或看结果再定义族。选择/调参后的普通区间通常未涵盖选择不确定性，必须说明。
- 敏感性分析有预先问题和不同假设；针对同 estimand 的稳健性与不同 estimand 的补充结果分列。不挑“最显著”的版本。
- 按 ASA S05 解释 P：其不代表假设为真概率或效应大小。区间跨零不等于无效，也不能解释为95%概率真值位于这一已计算频率学区间；结合兼容效应范围、临床界值和设计。

## 配对 cluster bootstrap 的精确契约

本模块脚本估计预先定义的逐行数值差 d=A−B。令 cluster g 有 n_g 个完整对，和为 s_g。`equal_cluster` = mean(s_g/n_g)；`equal_observation` = sum(s_g)/sum(n_g)。每次抽 G 个独立 cluster，有放回，保留重复抽中的次数；后者必须在该次抽样中重新计算分母。用 isin 保留被抽到 cluster 会丢失重复次数，是错误实现。

只在最高可辩护独立层级抽样；患者位于医院内且存在院内额外依赖时患者 bootstrap 不足。患者×靶点交叉泛化、分层抽样、固定设计、罕见事件、少量 cluster 需重新制定方差模型。该工具不实施自动 BCa、不估计训练/调参不确定性、不算 P 值。对零差退化区间必须报告，不能将 [0,0] 当作不存在其他误差的证据。
