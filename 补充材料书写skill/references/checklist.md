# 32项补充材料诊断清单

本清单是内部工作工具，并非经验证量表；不总分，不等同正式报告指南。默认级别仅指检查顺序，按实际影响分级。每项填写状态、位置、依据/核验层级、动作与复核状态。无材料时区分无法核实与已证实错误。

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| SUP01 | P1 | 当前正文、补充、图表及分析来源版本明确，实际读取范围和任务授权可追溯。 |
| SUP02 | P1 | 当前官方指南对应正确文章类型；补充可用性、文件拓扑、格式/大小、命名和引文要求有依据。 |
| SUP03 | P0 | 核心设计、比较、关键条件及结论判断证据在正文按要求可见，不只留see supplement。 |
| SUP04 | P0 | 改变核心结论的阴性、失败或反例未藏入补充而维持相反摘要/结论。 |
| SUP05 | P1 | 每项补充有明确问题/读者任务和来源，不以堆积输出制造工作量。 |
| SUP06 | P1 | 稳定内部ID、类型、显示编号、源文件/版本、正文入口形成完整台账。 |
| SUP07 | P1 | 补充结构和目录对应实际内容，无空模板、缺失文件或冗余的第二套失配目录。 |
| SUP08 | P1 | 数据源、获取/冻结版本、许可/访问状态、纳排/去重和分析集可辨认，未知项未猜。 |
| SUP09 | P0 | 分析/独立单位、重复/聚类关系、计数层级与最终分母正确对应。 |
| SUP10 | P0 | 输入、预处理、参考标准及参考标签访问明确，无未披露的循环定义或关键标签依赖。 |
| SUP11 | P1 | 模型/软件/权重/代码/依赖版本、参数和实际随机性设置足以理解关键步骤，未知值列查询。 |
| SUP12 | P0 | 主要比较、拟合/调参/测试边界、对照与资源差异透明，补充说明不掩盖不公平比较。 |
| SUP13 | P0 | 统计目标、效应/单位/方向、配对/聚类、区间/重采样单位和分析集有材料支持。 |
| SUP14 | P1 | 每项新增结果有实际方法依据，未做分析不写成已实施，新增方法有结果入口或缺失说明。 |
| SUP15 | P1 | 公式/算法符号、字段、单位与实现一致，未以伪代码或环境表认证可复现。 |
| SUP16 | P0 | 缺失、排除、失败、异常值和计分公开，未悄悄改变分母或只保留成功案例。 |
| SUP17 | P1 | 附加分析的问题、改变因素、保持条件及与主分析关系明确。 |
| SUP18 | P0 | 敏感性、消融、探索/事后、亚组和独立验证身份准确；没有升级因果、机制或临床收益。 |
| SUP19 | P0 | 保留阴性/不确定性和限制，未以非显著证明等效，补充发现的结论影响被处理。 |
| SUP20 | P0 | 数值对应原始输出及分析归属，主文、补充、图注与源图/表一致；冲突记录而非猜测。 |
| SUP21 | P1 | 每幅图有读者可独立理解的对象、条件、面板、数量/单位、统计量/误差线和必要符号定义。 |
| SUP22 | P1 | 每张表的标题、行列、单位/分母、缺失符号、比较与注释准确，不利/失败行保留。 |
| SUP23 | P1 | 数据/代码附件可按其用途读取，字典、版本、访问/许可和结果关联明确，未伪造公开状态。 |
| SUP24 | P1 | 类型+编号唯一且按实际命名规范管理；图S1和表S1不被误判重名，空缺/保留编号有理由。 |
| SUP25 | P1 | 正文/补充调用、目录、题注、范围/面板及文件台账指向正确对象，孤立或缺失项目处理。 |
| SUP26 | P0 | 引用目标存在且确实支持附近主张；结构正确与内容支持分别核验。 |
| SUP27 | P1 | 重排/合并/删除/重算有旧→新对照与影响扫描，范围外主文/附信/字段列待同步，不盲目全局替换。 |
| SUP28 | P1 | 补充参考文献遵循已核编号体例、元数据/支持关系和全文文献对应，未编缺项。 |
| SUP29 | P2 | 语言、术语、组名、指标、拼写及时间窗口与正文一致，细节足够而非重复整篇论文。 |
| SUP30 | P1 | 按实际匿名要求检查身份/元数据；不自动删审批、接受修订或把脱敏当已认证。 |
| SUP31 | P2 | 最终版本已逐页渲染检查图字、重叠、公式、表格跨页和可读性；仅分辨率/结构检查不算视觉通过。 |
| SUP32 | P1 | 读者版无内部诊断、查询、占位或旧日志；交付版本/文件清单与已核范围一致，开放项单列，未作虚假投稿就绪保证。 |
