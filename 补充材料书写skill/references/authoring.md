# 补充材料：写作与复核

## 目录

- 正文与补充分工；材料台账；结构与文风；补充方法
- 研究路线；附加结果；图注与表注；引用与编号；文件与版本

## 1. 先判正文与补充分工

| 信息 | 分工判断 |
| --- | --- |
| 核心问题、设计、主要比较/独立单位、关键输入与参考标准 | 正文须让读者辨认；细节可以补充扩展，不能仅留一个see supplement。 |
| 支持核心结论的主要结果、决定性条件、改变结论的失败或反例 | 正文至少给必要定量结果、限制与明确入口；不能藏入补充后维持相反摘要。 |
| 完整参数、环境、长推导、额外图表、非核心敏感性 | 有明确问题、来源及正文/补充链接时适合补充。 |
| 逐条可计算结果、数据字典、筛选记录、复现依赖 | 适合可编辑/机器可读附件或合规存储；正文说明用途与访问边界。 |
| 内部STOP/GO裁决、调试日志、占位任务、聊天记录、作者查询 | 属于内部工作材料。必要的科学事实经准确整理后可写，不能直接将内部报告当读者版。 |

如果期刊要求方法集中在补充，正文仍需提供其指南允许的必要研究设计与证据入口。对结论有实质影响的补充发现，必须提出具体正文修订；正文修改未授权时交付建议并标尚未同步，不越权改原文。

## 2. 材料台账

按最小有意义项目建立稳定内部ID，显示编号后定。记录类型、问题/主张、正文入口、来源文件/工作表/图面板/代码位置、版本或分析集、结果单位/分母、核验层级和状态。区分分析数据、统计输出、最终图、写作稿和投稿成品；不得凭新文件名认定内容最新。

材料冲突时列每个值与出处。可靠纠正依据明确时才能改数，记录影响的图、表、文字和字段；不选较好或较新的看似合理数字。哈希可绑定来源字节，但数字归属、样本含义和结论仍要人工核对。只有日志或代码静态检查，不能写独立重算已成功。

## 3. 结构与文风

按实际需要安排封面/目录、补充方法、附加结果/注释、补充图表与说明、数据/代码附件说明、补充参考文献。方法或图表少时无需长目录；未实施的模块省略或标不适用。目录必须对应实际内容和文件，不能把模板标题当已完成分析。

维持主文术语、语言和主要英美拼写体系。正文用完整、直接的学术句子；步骤、参数和数据字典适合表或列表。每个结果段说明问题、条件/方法差异、实际发现与边界，不展开新引言或宏大应用讨论。区分过去完成的工作和未来建议。纯润色不扩写未经材料支持的机制或局限，新增推测放作者查询。

## 4. 补充方法应写什么

方法要让读者辨认关键决策并可复现重要处理，不只是把正文句子加长。按适用性补足：

- 数据源/许可、获取日期和版本/登录号；纳排/筛选流程、身份关联、去重、失败/缺失处理以及每层最终样本数。
- 主要与次要问题、分析单位、独立单位、结局/指标定义、方向、单位与聚合规则。
- 原始输入→转换/预处理→模型/算法→评价的顺序；参数、阈值、数据依赖、拟合范围和对照。
- 实际软件/依赖/模型/权重版本、仓库提交或发布版、命令/配置与随机性设置。未知硬件/种子/版本不能填写常见默认值。
- 统计目标、配对/重复/聚类结构、效应量与区间的构造、重采样单位与次数、分析集、失败计分、多重比较及敏感性定义。没有做某调整不能补写已做。
- 与正文方法的承接；每个新增结果都有对应方法，每个新增方法指向实际结果或解释为何无结果。
- 公式逐个定义符号、输入范围和单位；算法伪代码与实现一致。种子与依赖表有用，但不等于已证明可复现。

时间点与窗口、相对与绝对效应、CI/SD/SE、风险/率/优势比不可互换；保护否定、失败、探索/事后身份和不确定性。不编审批、同意或注册，不因使用公共数据就自动写无需伦理审批。

## 5. 根据研究路线加细节

只启用实际相关路线，不要求每篇同时覆盖。

| 路线 | 重点补充 | 结论边界 |
| --- | --- | --- |
| 生信方法比较/公开数据重分析 | 实际数据冻结版本、样本/基因/节点/任务集合、ID映射、交集和筛选、指标符号/阈值、参考标准、聚合及失败计分、最接近方法公平设置。 | 有符号关联分数不自动代表生物因果，参考网络/外部指标的差异不能说成普遍赢家。 |
| 影像模型/预处理审计 | 数据集/患者/目标关系、提示形成、ROI/裁剪/坐标/重采样、是否访问参考标签、模型/权重/代码版本、失败例与独立单位。 | 依赖参考标签的步骤及其结论影响要在正文可见；某代码路径发现不泛化至全部模型/论文。 |
| 冻结模型组合/路由 | 各专家输入与资源、路由可用信息、拟合/选择/测试隔离、简单基线、条件收益、每场景与失败分布。 | 模型组合不改称新基础模型；事后最佳选择不能冒充可部署路由。 |
| 化合物/药物公共筛选 | 化学身份/结构去重、测量单位、assay版本和有效范围、阈值、划分/邻域隔离、缺失/截尾、训练可见范围和聚合。 | 活性/评分不自动代表结合、机制、临床疗效；探索与验证身份不改写。 |
| 执行/数值漂移审计 | 发布时/现代环境、工具链与依赖、尝试注册、输入校验、输出比较单位、隔离修复/回退、可归因变化与未解决环境。 | 开发/取证案例与确认性样本分开；不能把安装失败写成方法无效，静态检查不写成因果验证。 |
| 临床/综述研究 | 按真实设计核查官方报告指南的相关方法/检索/筛选/结局细节；患者与观察次数、混杂/缺失/偏倚处理按实际做法报告。 | 不把计算研究自动套成试验，不把正式报告清单当已认证科学质量。 |

## 6. 附加结果与敏感性分析

先给该分析回答的具体问题、改变的因素与保持的条件，再给效应/不确定性、分母和方法入口，最后说明它支持或未支持哪个原主张。多因素同时改变时透明报告，不能硬写成只改一个因素。消融、亚组、鲁棒性、失败分析和真正独立验证分别命名；不能将补充分析改称外部验证。

处理无显著、收益变小、反向和失败结果。关键反例改变核心结论时同步正文建议，不继续写所有设置均稳健。把既有探索分析放进补充不会变成预设。无足够依据区分分析未实施、未提供结果与实际分析失败，不将三者合并为阴性结果。

## 7. 图注、表注与附件

图注给编号与描述性标题、研究对象和条件、面板/颜色/符号、实际数量与计数单位、度量/方向/单位、汇总及误差线定义、统计方法/比较和必要缩写。敏感性图说明改变了什么；不凭图形猜P值、区间算法或样本量。保留原始图像比例、坐标和参考线，实际看最新图；800dpi等分辨率不代表无重叠或截字。

表题短而明确，表注定义单位、分母、缺失符号、比较/基线、统计量与限制；行/列标签对应源数据，保留不利与失败行。独立文件的每张表附足够读法。表格按用户三线表偏好及已核指南排版，合并表头或宽表人工复核；可计算大表用适当XLSX/CSV等实际允许格式，不只截图或不可选文本PDF。

数据/代码附件说明内容、字段含义、单位、来源、版本、访问/许可及如何连接论文结果。不把尚未公开的路径改成公开URL，不编DOI或登录号。期刊要求代码存储时，单个补充文本或原始日志不能替代实际可用代码。

## 8. 引用与编号

以类型+显示编号作为键。例如Supplementary Figure S1与Supplementary Table S1不同；Supplementary Methods S1也不是图S1。编号按期刊实际要求，有的用S1，有的用Supplementary Figure 1，Extended Data另管。

重排前保存稳定ID与旧编号，重排后按内容任务逐处替换正文、补充正文、目录、图题、图注、表注、文件清单及在授权内的回复/附信。检查单复数、范围引用、面板后缀和引用目标的实际内容；同一个数字出现在参考文献中不能一起替换。保留正文中介入口：每个独立附件应有明确调用，每个显示项目至少由正文或补充叙述引导；不机械要求每个补充面板在正文逐一列出。

补充参考文献是否与正文共享、延续或单独编号必须核官方要求；不默认任何一种。引文标记移动时保留支持关系，不能只核编号存在。没拿到文献或显示文件时相应事实/视觉标无法核实。

## 9. 文件与版本

正文、补充、图像、表和统计输出须来自已确认的同一分析状态；旧分析可作为明确历史对照保留，不能混进当前结果而不标注。合并稿目录顺序与文件台账一致，不手工维护失配的第二套清单。文本检查覆盖正文、表格及嵌套表、页眉/脚注/图注、有效修订文本，不能只读document.paragraphs。

保持有效修订与作者批注；不自动清理身份，按已核匿名要求处理文件名、图内文字、元数据、批注与相关附件。渲染并看最终DOCX/PDF每页和嵌入图；确认公式、表格跨页、读法和链接正常。记录真正完成的检查层级，格式或文件哈希通过不能标内容全部通过。

最终读者版不出现内部质量裁决、作者查询、占位符、TODO、审计JSON、工作流日志或机器本地路径；例外是具有科学用途且被解释的可复现实例命令，使用通用路径。官方报告指南表可按要求另交，内部诊断清单不能改名充当官方清单。
