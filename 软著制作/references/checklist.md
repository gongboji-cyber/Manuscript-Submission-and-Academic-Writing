# 36项软著申请前审计清单

状态：PASS / PARTIAL / FAIL / NA / UNKNOWN。级别P0（真实性、权属、保密、材料）、P1（一致性/排版）、P2（文字）。逐条记录证据位置、问题、修正和复核；UNKNOWN不等于PASS。

| ID | 核查项 | 级别 |
|---|---|---|
| SC01 | 真实程序存在且冻结版本/SHA256 | P0 |
| SC02 | 软件边界、入口、已实现功能清楚 | P0 |
| SC03 | 运行测试有真实证据，不伪称已测试 | P0 |
| SC04 | 开发完成和发表状态有可靠依据 | P0 |
| SC05 | 名称、简称、版本经申请人确认 | P1 |
| SC06 | 作者、著作权人、合作身份核实 | P0 |
| SC07 | 校院、职务、委托、任务开发权属已审 | P0 |
| SC08 | 许可、转让、继承/受让证明按需具备 | P0 |
| SC09 | 第三方软件/模型/数据许可建档 | P0 |
| SC10 | 无将第三方或AI虚构代码冒充原创 | P0 |
| SC11 | 全部交存代码来自同一冻结版本 | P0 |
| SC12 | 选入源文件范围、顺序和哈希有据 | P1 |
| SC13 | 代码行次序与原文件行号可追溯 | P0 |
| SC14 | 前后连续30页或不足60页全交已核 | P0 |
| SC15 | 程序每页50行及例外经PDF实测 | P0 |
| SC16 | 机密例外交存依第十二条另行核定 | P0 |
| SC17 | 无填充、复制、编造代码凑页数 | P0 |
| SC18 | 乱码、超长行、缩进、裁剪已核 | P1 |
| SC19 | 无凭据、患者/个人敏感信息外泄 | P0 |
| SC20 | 文档只陈述软件实有功能 | P0 |
| SC21 | 主要功能对应源程序及运行证据 | P0 |
| SC22 | 真实截图/设计示意图正确区分 | P0 |
| SC23 | 菜单/命令/参数/环境前后一致 | P0 |
| SC24 | 文档前后30页或不足60页全部已核 | P0 |
| SC25 | 文档每页30行及特例已渲染审查 | P1 |
| SC26 | 文档/源码PDF A4版式页码正常 | P1 |
| SC27 | 表单字段有事实支持，不伪填日期/主体 | P0 |
| SC28 | 源码量/语言/部署环境和申报一致 | P1 |
| SC29 | 软件全称/版本/权利人在各材料一致 | P0 |
| SC30 | 身份与权属证明齐备或明确缺口 | P0 |
| SC31 | 登记中心本次流程和材料要求已核 | P1 |
| SC32 | 不承诺证书、专利权或临床批准 | P0 |
| SC33 | 未公开上传私有源码、证件、病历 | P0 |
| SC34 | DOCX及PDF按实际渲染验收或明确HOLD | P1 |
| SC35 | 申请人审查并确认所有申报事实 | P0 |
| SC36 | 若有补正通知已逐点复审 | P1 |

**STOP_INELIGIBLE_OR_RIGHTS_CONFLICT**：无真实软件或已发现无法忽视的权属冲突。
**HOLD_EVIDENCE**：P0 UNKNOWN/FAIL或平台/代码/渲染关键证据缺口。
**GO_TO_HUMAN_REVIEW**：P0通过或确认不适用，程序/文档/表单三向核验并已逐页渲染，仍需申请人审阅与机构审核；不等于成功登记。
