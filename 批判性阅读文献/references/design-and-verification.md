# 研究分流与核查

## 设计路线

先确定主张/设计，再选核查领域。下表是本skill的阅读问题，不是官方工具全文。正式评价须读当前官方版本、适用条件和信号问题，逐项给依据；局部检查称“按相关领域核查”。

| 类型 | 首要核查 | 适用入口 |
| --- | --- | --- |
| 随机干预 | 随机化/隐藏、目标估计量、偏离干预、失访、测量、选择报告；ITT/依方案含义 | RoB 2匹配平行/整群/交叉版本；报告规范另核 |
| 非随机干预/目标试验 | 纳入/分组/零点/随访一致、未来条件、适应证混杂、删失/加权假设 | ROBINS-I，注明版本及草案状态，不泛用于全部观察研究 |
| 观察性暴露/病因 | 时序、混杂、选择/碰撞、反向因果、匹配和单位 | ROBINS-E等匹配工具，核实范围 |
| 诊断/筛查 | 患者谱、阈值、参考标准、盲法、核验/时序、不可判定/失访 | QUADAS当前版本；2026-10-09官网已推荐QUADAS-3，未来重核；STARD系列是报告规范 |
| 临床预测/AI | 数据源、预测器时点、结局、开发/评价分开、泄漏、划分、校准/用途 | PROBAST+AI等当前适用工具；TRIPOD系列是报告规范 |
| 系统综述/合并 | 方案、检索、重复样本、设计、偏倚、合并模型、异质性、零事件/缺失证据 | AMSTAR 2等；GRADE按问题/结局的证据体；PRISMA是报告完整性 |
| 诊断标准/共识/指南 | 定义可一致执行、推荐与证据匹配、研究定义/临床决策分开 | 实际共识过程、匹配指南框架和验证，不把共识当独立真值 |
| 生信/冻结模型基准 | 身份映射、输入与参考、指标、泄漏、预处理/提示/阈值、公平比较 | 具体协议/代码/数据；不凭医学模型名称套一个总分 |
| 叙述性综述/机制 | 推理链、偏选证据、关联/因果、表型/模型迁移 | 按文章类型评价，不因缺实验自动否定综述 |

不同问题不共用RCT证据阶梯。GRADE是给定问题/结局的证据体判断，单研究证据体亦可评价，但须明确范围并作领域判断，不给论文整体机械评级。算法整理评级不能把语义判断变成真值。

## 数值复核

抄录数量、分母、单位、时间窗、分析集及估计方法，保存定位并独立核一遍。用小计算裁决具体疑点，不任意换方法制造更强批评。

### 分类与诊断

- 区分patients、encounters、样本、病灶、图像及检验次数。
- 交叉分类保留一致/不一致组及证据路径；新增病例不自动证明增敏或降低特异度。
- 富集可能改变疾病谱，不仅改变患病率；其敏感度不能直接搬到连续筛查。PPV依赖患病率与核验。
- 阳性预测比例不需真值；特异度、PPV、敏感度需对应真实结局。未核验阴性不自动当无病；部分核验不能写成完全无随访。
- 指标检验参与参考诊断时区分一致性/准确性；死亡、治疗响应或影像变化不是独立证明侵袭的充分证据。

### 人时与时间线

- 若粗率r以每100人年计且口径一致，人时=events×100/r。先考虑四舍五入、加权/标准化、结局分母与单位。
- 单次每人随访上限T，人时≤N×T。重复事件不自动增加人时；顺序试验重复参与可增加entry-level人时，须核patients/entries与依赖处理。
- 画清纳入、暴露定义、分配、index date、零点、随访。日期名称不一致不自动证明immortal time；具体定位未来存活条件及被错误计入的时段。
- 亚组只有在互斥穷尽且同分析集、结局/时窗时应加和；否则先澄清，不能宣布算错。

### 区间与场景

- 由百分比重构整数先保留所有四舍五入兼容值。按声明的独立层级、配对/分层、权重、percentile/BCa等复核；聚合数常不能精确还原区间。
- 普通非分层有放回bootstrap的N人中仅1阳性，未抽到此人的概率=(1−1/N)^N；不是分层、平滑或模型区间通则。先核实际程序，不能拿另一种CI当唯一正确。
- 比较模型/估计器时报告点估计、区间、异质性参数、零事件处理与变动条件；跨P=0.05不证明效应归零/反向。一亚组显著另一不显著不证明交互。
- tipping-point的额外漏检h是情景而非新发现患者；给h=0并说明分子、分母/核验条件。不能把假设漏诊写成实测。
- 风险cut-off不能自动变干预阈值；净获益还需治疗益处、风险、表型和干预证据。

## 代码、公式与重算

明确原文→跨材料→静态文件/代码→最小执行→独立重算/受控归因五层。

- 锁定实际发表commit、输入、参数/环境。可疑分支可能没参与分析；静态出现GT不证明全部结果泄漏。
- 用已知性质的合成反例查公式，例如纯加性是否被判协同。合成失败只是条件性公式证据，再查真实实现/输出。
- 先忠实重现，再改一个可解释条件。保留原输出、改动、环境、独立单位和随机性；患者是独立单位时不以多图/器官扩大n。
- 分开方法不适用、软件故障、版本漂移、输入缺失、环境未解决；失败不直接证明方法无效。
- 固定其他条件才谈归因；无发布时环境称现代执行审计，开发案例不混入确认集。
- 数据许可/访问、代码开放和实际输出有效性分别核。缺数据不自动证明不可复现，可下载不自动证明正确。

每个结果记录输入/版本、公式/代码、实际运行状态、输出/单位、影响和不可推论项。未运行写计划；无真实输入或明确假设的重算不作为确定性错误证据进入letter。
