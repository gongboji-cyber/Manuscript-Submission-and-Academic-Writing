# 36项批判性阅读诊断清单

记录通过/部分通过/不通过/不适用/无法核实、位置、层级、实际影响P0/P1/P2或—、反证与动作。状态评本次核查是否成立，不自动等于论文有无偏倚；不凑缺点，不累加总分。

| ID | 核查问题 |
| --- | --- |
| CR01 | 身份、版本、类型与实际阅读范围是否明确？ |
| CR02 | 相关主文、补充、图例、脚注、协议是否已读，缺失是否如实记录？ |
| CR03 | 勘误、撤稿、既有评论/回复是否核查，失败是否区别于无结果？ |
| CR04 | 用户样稿、原文、外部证据、自己重算是否分开，未以录用/声望作证据？ |
| CR05 | 研究问题、贡献与未承诺的问题是否准确还原？ |
| CR06 | 人群、条件、比较、独立单位与主要结局是否明确？ |
| CR07 | 核心主张是否锚定真实数据/方法并保持原强度？ |
| CR08 | 描述、预测、诊断、因果、机制、决策及推断前提是否分开？ |
| CR09 | 设计分流、工具版本和适用范围是否匹配并已核？ |
| CR10 | 缺报告、未知、偏倚/缺陷、报告规范与评价工具是否分开？ |
| CR11 | 纳入、分组、暴露、零点、随访/删失是否满足目标比较？ |
| CR12 | 混杂、未来条件、碰撞/选择、测量问题是否有具体机制？ |
| CR13 | 定义是否能一致执行，图表/正文适用条件是否完整核查？ |
| CR14 | 分类增量/准确性、共享证据一致性/独立真值是否分开？ |
| CR15 | 富集/部署队列、核验路径是否分评，未核验阴性是否避免当真阴性？ |
| CR16 | 风险预测/代理结局是否避免替代干预净获益/硬结局？ |
| CR17 | patients、entries、重复样本、事件、分母/人时是否同口径？ |
| CR18 | 亚组加和是否确认互斥穷尽、分析集、时窗、四舍五入/加权？ |
| CR19 | 区间重构是否匹配独立单位、配对/分层、方法，近似是否说明？ |
| CR20 | 点估计、精度、显著性、临床意义是否分开，未把非显著当无效/等效？ |
| CR21 | 亚组/探索、交互、多重比较、注册/预设身份是否准确？ |
| CR22 | 缺失、核验、失败、tipping-point是否保持观测/假设边界？ |
| CR23 | 引文身份是否核实，访问失败是否未被宣布虚构？ |
| CR24 | 引文语义是否支持主张并保留设计、人群、表型、时窗？ |
| CR25 | 是否双向检索、读取已有解释，而非仅搜批评？ |
| CR26 | 最强作者解释、撤销条件是否逐点列出？ |
| CR27 | 代码/公式是否分静态疑点、实际执行、输出影响和归因？ |
| CR28 | 重算是否保留真实输入/版本、原方法、关键改动和实际运行状态？ |
| CR29 | 是否分现代/历史环境、开发/确认、技术失败/科学失效？ |
| CR30 | 是否具体检验影响哪项结论，未从局部错升级全文无效？ |
| CR31 | 已消除疑点是否撤销，未核实是否保持条件判断？ |
| CR32 | 是否避免动机/不端推断、固定缺点、总分、单篇机械GRADE？ |
| CR33 | 评论是否新增、重要、可核验，区别于一般局限？ |
| CR34 | 是否给可实施修正、结束条件并保留有效贡献？ |
| CR35 | 写letter时是否符合已核入口/格式和事实/引文/声明边界？ |
| CR36 | 是否交代核查层级、未审范围、判定，保护隐私和发送/投稿授权？ |
