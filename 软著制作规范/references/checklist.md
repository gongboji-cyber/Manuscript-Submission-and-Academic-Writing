# 软著提交前自检清单

状态只用：通过 / 部分通过 / 不通过 / 不适用 / 无法核实。

影响级别：

- P0：真实性、权属、软件不存在、伪造源码、核心材料与申请主体不一致；
- P1：申请字段、鉴别材料、名称版本、连续性、页数行数、文档功能不一致；
- P2：排版、页眉、截图清晰度、语言和文件命名。

## A. 软件真实性

- [ ] 项目可访问，关键源码真实存在
- [ ] 软件主要功能能回到代码/界面
- [ ] 未编造功能、截图或源码
- [ ] 软件版本有可核来源
- [ ] 开发完成日期有合理依据或已由申请人确认

## B. 权属

- [ ] 申请人身份明确
- [ ] 独立/合作/委托/职务开发已判断
- [ ] 合作开发有权属说明
- [ ] 委托开发查看合同
- [ ] 修改他人软件有许可
- [ ] 受让/继承有证明
- [ ] 无明显他人版权声明冲突

## C. 第三方代码

- [ ] 依赖目录已排除
- [ ] 自动生成代码已识别
- [ ] vendored 代码已识别
- [ ] 关键源码不主要由第三方构成
- [ ] 高风险开源许可证已列出
- [ ] 无来源不明的大段复制代码

## D. 申请表

- [ ] 软件全称一致
- [ ] 软件简称一致
- [ ] 版本号一致
- [ ] 著作权人一致
- [ ] 开发方式有事实依据
- [ ] 权利取得方式有事实依据
- [ ] 发表状态已确认
- [ ] 开发完成日期已确认
- [ ] 主要功能不夸大
- [ ] 技术特点与项目一致
- [ ] 开发环境与运行环境未混淆
- [ ] 编程语言与源码一致
- [ ] 源程序量可复算

## E. 源程序鉴别材料

- [ ] 采用的是申请软件本身源码
- [ ] 普通交存前段连续
- [ ] 普通交存后段连续
- [ ] 不足 60 页时未人为补造
- [ ] 每页代码行数达到当前规则要求
- [ ] 页眉软件名/版本一致
- [ ] 页码连续
- [ ] 字体和换行未导致大面积代码不可读
- [ ] 未泄露密钥/密码/患者或用户敏感数据
- [ ] 若例外交存，方式符合官方规则并有记录

## F. 文档鉴别材料

- [ ] 文档类型合理
- [ ] 功能均为真实功能
- [ ] 菜单、按钮、接口名称与软件一致
- [ ] 截图来自真实软件
- [ ] 截图无敏感信息
- [ ] 文档名称/版本一致
- [ ] 文档行数和页数满足当前要求
- [ ] 不足 60 页时按规则处理
- [ ] 无营销式虚假性能声称

## G. 交叉一致性

- [ ] 申请表 ↔ 源码页眉
- [ ] 申请表 ↔ 文档封面
- [ ] 申请表 ↔ 软件实际标题
- [ ] 申请表 ↔ 版本文件
- [ ] 功能描述 ↔ 真实模块
- [ ] 运行环境 ↔ 实际依赖
- [ ] 截图 ↔ 文档操作步骤
- [ ] 著作权人 ↔ 权属文件

## H. 当前官网核验

- [ ] 已记录核验日期
- [ ] 当前登记入口已确认
- [ ] 当前在线字段已确认
- [ ] 当前上传文件格式已确认
- [ ] 当前实名认证/主体材料要求已确认
- [ ] 当前补正/受理流程已确认

## 最终裁决

### GO
无 P0；P1 已解决；当前官方要求已核验。

### HOLD
软件和源码真实，但存在未确认权属/日期/版本/官网字段/分页问题。

### STOP
存在伪造、冒用他人软件、明显无权申请或软件主体不存在。
