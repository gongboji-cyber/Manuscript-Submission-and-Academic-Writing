# Cover letter：用准确证据说明为何值得编辑审阅

把附信写成简明的编辑判断依据：问题为何值得研究，本稿提供什么新增证据，为什么适合这本期刊和它的读者。用尊重、克制和准确体现诚恳，不靠恭维、宏大承诺或反复恳求。按L01—L12逐项检查。

## 1. 先核查，后起草

1. 阅读当前主文、标题页和必要补充，锁定文章类型、实际贡献、核心发现和限制；资料不足时只写有依据内容，其余标待确认。
2. 从期刊或出版社官方页面核查当前编辑姓名、职务、多人负责人情况及作者指南。记录URL、访问日期、实际阅读范围和所用称呼；搜索摘要或第三方简历不足以确认现职。
3. 区分主编、编委、执行编辑、栏目编辑和实际处理编辑。投稿指南指定收件人或返修已有处理编辑时依依据称呼；没有指定时可用已核实的负责人或中性Dear Editor。无法确认姓名/学位/职称时不猜，不强行填写Professor或Dr。
4. 阅读官方aims and scope、该文章类型要求和cover letter要求。仅在能具体帮助解释匹配时阅读该刊相关原始文章，不为装饰而罗列引用。
5. 将前人启发写成可核对的知识连接：已有工作回答了X，本研究进一步检验Y。用户没有提供真实研究动机时不编写“我们看到某结果后决定……”等个人历史。不要把学术缺口写成人身否定。

## 2. 起草结构

采用以下压缩结构，按官方指南和文章类型调整，不强制每点独立成段。无明确要求时可把约250—400英文词作为内部起草目标，不声称这是期刊通用规定。

| 功能 | 应写内容 | 删减判断 |
| --- | --- | --- |
| 提交信息 | 稿件标题、期刊及文章类型；称呼准确。 | 不长篇寒暄或赞美期刊地位。 |
| 背景与启发 | 1—2句说明具体未决问题，以及已有工作如何引出本研究。 | 不搬运整个引言、作者名单或虚构首次。 |
| 工作与贡献 | 交代设计/对象，选择最有区分度的1—3项贡献；必要时给一个能说明量级的主要结果。 | 不罗列所有实验；阴性结果要说明排除了什么、限定了什么。 |
| 期刊与读者 | 将研究内容对应官方范围，点名相关读者及其会遇到的具体问题；说明稿件可提供的认识或行动依据。 | 不只写fits the scope、broad interest、prestigious journal。 |
| 实践及科研启发 | 选最相关的一两点，给适用条件和可检验的后续方向。 | 不强迫每篇写全球卫生；不能证明获益时写评价/设计启发，避免患者结局承诺。 |
| 必要声明与结尾 | 根据已核实要求和作者事实加入声明，简短感谢编辑审阅，署名信息按提供内容填写。 | 未确认声明另列待确认；不伪造全体作者同意、原创性、独家投稿或签名。 |

## 3. 区分几种“重要性”

- 科学贡献：改变了哪项认识、边界、证据或方法能力？必须指向本文。
- 期刊匹配：哪些官方领域和文章类型与本稿内容直接对应？期刊声誉不构成匹配理由。
- 读者兴趣：哪些读者能因此更好地作什么判断？不要声称知道编辑个人兴趣。
- 全球卫生/行业启发：如果没有跨地域、资源、临床或行业决策相关依据，省略或标不适用。通用方法学启发不等于已证实全球临床效益。
- 未来科研启发：指出应检验哪个解释、采用何种设计/对照或更改何种评价报告，不以空泛更多研究结尾。

保留限定条件，例如特定数据、版本、提示、阈值或场景；不要为了附信“吸引人”删掉决定结论成立的条件。不必罗列全部局限，但必须保留一旦省略就会误导编辑的边界。

## 4. 输出与复核

1. 将附信的贡献与关键数字对应到正文/图表；逐项核对L01—L12及标题页、正文与投稿字段一致性。
2. 附信之外给简短核查记录：编辑官方出处及日期、范围/类型依据、贡献证据位置、未确认声明。不要把内部诊断或检索过程塞进信中。
3. 如果未能核实编辑，使用中性称呼继续起草并注明边界；期刊信息不足时保留具体待确认项，不能臆造定位。
4. 交付完整可编辑信或用户要求的文本形式；使用对应写作/文档技能。只写附信时不自动全文审稿；核心主张仍做必要核查。
5. 起草、保存和上传文件不授权发送邮件或在投稿系统提交。仅按明确用户指令执行发送/提交。

## 5. 学术表达编辑

开始编辑前按句记录受保护内容：稿件标题、期刊/类型、作者身份、设计/对象、结果与时间点、数值/分母/单位/区间、引用支持关系、限定条件和投稿声明。保留英美拼写的主要体系及作者提供的适当语体。仅润色默认局部编辑；段落重排须在授权范围内。

1. **核对主张。** 每个贡献与启发对应正文位置；关联不升级为因果，技术性能不升级为患者获益，单场景不扩大到全球。未知声明查询作者，不代承诺。
2. **压缩论证。** 每段承担明确任务，直接解释背景如何引出问题、发现如何支持贡献、哪些读者能使用该认识。用真实逻辑衔接，不靠反复递进词。
3. **修句与术语。** 明确行动者和比较对象，减少名词堆叠、重复修饰、宣传与寒暄。主动/被动按重点选择，技术名称保持稳定；不以复杂词汇、固定句长或词汇黑名单定义academic。
4. **逐句保真。** 对照原文和稿件依据，复核结果归属、引用归属、否定、确定性及声明。数字集合一致也可能交换了结局；修改有科学含义时单列原句、改句、依据和相关L项。

仅要求润色时先给完整信，再给必需作者查询与实质变化说明；其余交付沿用SKILL.md。L05/L08/L10覆盖贡献与证据边界，L11覆盖表达，L12覆盖声明，无需另增重复评分项。不能核实事实或含义时指出具体位置和所需材料。无需每篇同时写全球卫生和行业价值，不能为吸引编辑而发明启发。

与正文润色串联时以同一稿件版本和主张对应表为准；排版授权时再使用format-academic-word，完成最终文件的内容与渲染复核。仅写信不自动格式化全文。
