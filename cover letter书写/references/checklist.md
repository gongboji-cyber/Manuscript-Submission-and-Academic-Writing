# Cover letter的12项自查

逐项记录状态、原文/材料位置、依据和修正动作，不用总分认证科学质量。默认级别仅表示优先检查顺序，按实际影响判定问题。

- P0：主张/数字/声明有已证实关键错误，或具体关键待核矛盾可能影响信的真实性。
- P1：影响准确称呼、期刊匹配、读者判断或投稿合规。
- P2：语言、结构、礼貌与阅读效率。

仅未提供材料不自动定为P0；明确区分事实未核、报告缺项和已证实问题。


仅检查附信材料与适用要求；不因未核实特定处理编辑而捏造姓名，也不以全球影响为必填项。阅读references/authoring.md执行具体流程。

| ID | 默认级别 | 检查项与通过依据 |
| --- | --- | --- |
| L01 | P1 | 当前编辑姓名、职务、拼写及称呼由官方来源核实；不猜处理编辑或学位，无法确认时用中性称呼并列核查边界。 |
| L02 | P1 | 信首交代准确稿件标题、期刊与文章类型；与投稿文件和系统字段一致。 |
| L03 | P1 | 简洁说明具体研究背景、未决问题及重要性，不写长篇领域综述。 |
| L04 | P1 | 前人启发与最近工作被准确、公允地概述；若声称受某研究启发，有实际依据，不虚构个人动机或贬低前人。 |
| L05 | P0 | 说明做了什么和实际新增什么；最重要发现及必要数值有正文依据，不把复现、审计或新验证包装成新算法。 |
| L06 | P1 | 期刊匹配有已核实的范围、文章类型或编辑定位依据，不只说期刊声誉高或曾发表类似论文。 |
| L07 | P1 | 点明编辑可判断的具体发现与相关读者群，并说明对其研究/实践问题有什么作用，不猜编辑个人喜好或泛称所有人感兴趣。 |
| L08 | P0 | 全球卫生/行业启发仅在相关且有依据时出现，交代适用对象、条件和实际决策；未验证患者获益不写成既成事实。无此相关性可不适用。 |
| L09 | P1 | 后续科研启发具体指向可检验的问题、设计或评价改进；无实际增量时省略，不用more research is needed代替内容。 |
| L10 | P0 | 附信与正文主张强度、数值和限制一致；不以首次、突破性、普遍适用等无依据断言加强卖点。 |
| L11 | P2 | 语气诚恳、礼貌、平等，简短致谢；避免过度恭维、反复恳求和摘要复制，篇幅服从官方要求。 |
| L12 | P1 | 必要原创性、独家投稿、作者同意、利益冲突、相关稿件/预印本等声明由作者事实支持且符合当前指南；未知项明确待确认，不自动签名或发送。 |
