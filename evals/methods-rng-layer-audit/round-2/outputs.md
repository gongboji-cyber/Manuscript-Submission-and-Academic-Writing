## Output X — baseline `90f43f2`

### Case A

裁决：尚不支持作为主结论的数值优劣比较。

依据：外层种子未控制 `random_state=None` 的估计器随机性；同一外层种子复跑已改变排名和胜者。五个外层种子各运行一次，无法分离外层与估计器波动，该 SD 不能称为“完整不确定性”。

最小下一步：固定输入、划分和环境，在外层种子 20261020 下显式控制估计器种子并确切复跑；再用预先确定的多个估计器种子检查条件内波动。随后才评估跨外层种子的配对比较及精度。

可报告边界：可报告现有运行结果及已观察到的排名不稳定；不能宣称稳健胜出。上述检查为建议，未执行。

### Case B

裁决：确切可重复性不足以证明稳健优势。

依据：输出哈希一致支持指定配置下的重复性；20 个预声明估计器种子中有 7 次更换优选方法，说明方法选择对种子敏感，但不单独证明平均优势不存在。

最小下一步：利用已有全部 20 次结果，按种子配对报告方法差值、差值分布、排名切换及 Monte Carlo 精度；按事先定义的优势标准判断，不能挑选有利种子。

可报告边界：可报告确切重复性和观察到的 7/20 切换；尚不能声称种子稳健的优越性，也不能据此声称等效。

### Case C

裁决：无需创造随机种子；随机种子控制不适用。

依据：给定流程没有随机或已知非确定性环节，且两次相同输入产生相同输出哈希。

最小下一步：核对均值差的方向、分母、缺失处理及公式，保存输入、代码、环境和输出哈希；种子字段注明“不适用”。

可报告边界：可报告冻结 CSV 中的描述性均值差和此次复跑一致性；不能由此自动推广总体推断或因果结论。

### Case D

裁决：可报告观察到的非确定性；部署通过结论应暂停。

依据：冻结输入与设置仍出现三个不同得分，且阈值判定发生翻转。无种子接口限制了控制能力，但不能据此确定差异的具体来源。

最小下一步：保存三次原始响应、模型/版本、时间、请求标识及设置；预先制定有限重复预算、阈值误判容忍度和停止规则，再检验服务输出的决策稳定性。

可报告边界：可报告三个得分及阈值跨越事实，并披露无法控制种子；三次调用不足以确定稳定分布或部署可靠性。未解决的阈值判定不稳定阻止部署结论，而非阻止报告全部描述性结果。

### Case B
