## T1：公开多组学数据批量选题

**选择与顺序**

1. `coordinate-research-workflow`：冻结范围、检索/全文预算、数据许可及本轮授权。
2. `research-topic-selection`：执行发现漏斗、候选去重与 F–M–D–U–C 组合，建立 G0–G4 门槛账本。
3. `retrieve-and-match-references`：候选通过浅筛后，核查最近邻原始研究；只有摘要时保持 `abstract-read`，不得据此宣称创新。
4. `guide-research-methods-statistics`：仅在候选形成明确问题且进入正式设计时接手 estimand/SAP；本轮不进入正式分析。

**触发条件**

- 有具体候选命题后才启动主张级最近邻核查。
- 有真实字段和小样例后，才核验 join key、标签编码、重复对象及来源谱系。
- 只有完整联合交集、独立性和精度均已核实，才可能通过 G3。
- G0–G4 全部 PASS 后才可能转为 `GO_MINIMAL_PILOT`。

**当前裁决/停止点**

- 当前主裁决：`EXPLORE_ONLY`。
- 题库组合裁决：`NO_GO_YET`。
- 当前状态约为：G0–G3 `UNKNOWN`，G4 `NOT_TESTED`，G5 不适用。
- 在本轮授权内，最多可完成：有界文献检索、候选浅筛、部分最近邻全文核查、estimand 草案，以及目录/小样例层面的 join 规则验证。
- 即使小样例可联结，也不能外推完整联合交集、标签独立性或有效样本量。因此本轮最高只能把有潜力候选推进至 `HOLD_NEED_EVIDENCE`，不能达到 `GO_MINIMAL_PILOT`。

**仍缺证据**

- 每题可证伪命题、受益方和最小有意义改变。
- 最近邻 Methods、Results、相关 Supplement 及主张级增量矩阵。
- 统一 estimand、观察单位、权重和识别假设。
- 完整 `N0 → N_key → N_label → N_independent → N_eval` 分母。
- 联结键唯一性、不匹配原因、有效标签、缺失机制。
- 训练/调参/测试/标签来源谱系与泄漏检查。
- 强基线、公平信息预算、精度目标及冻结试点结果树。

**未授权而未执行**

- 批量下载或全库解析。
- 模型训练、调参、正式试点或功效性结论。
- 投稿、发送或公开材料。

## T2：内部 AUC 差异解释为机制发现

**选择与顺序**

1. `coordinate-research-workflow`：将任务限定为候选审计，不执行分析。
2. `research-topic-selection`：作为主控，审查 G0–G4。
3. `retrieve-and-match-references`：取得并核实最近邻论文正式版本、Methods、Results、Supplement、代码和数据说明。
4. `critically-read-literature`：还原论文实际单位、比较、结果和推断边界，建立“机制主张—证据”图。
5. `guide-research-methods-statistics`：仅在材料齐全后冻结共同 estimand、独立单位、配对 AUC 比较、强基线和泄漏图。
6. 返回 `research-topic-selection` 给唯一 GO/HOLD/STOP 裁决。

**触发条件**

- Methods/Results/Supplement 未读时，G1 必须保持 `UNKNOWN`。
- 若三个模型不共享同一结局、评价样本或信息预算，不得比较为统一 estimand。
- 若只有 AUC 差异而无可区分替代机制的正交测量、干预、消融或识别设计，机制结论不能成立。
- 只有 G0–G4 全 PASS 才可考虑最小试点。

**当前裁决/停止点**

- 主裁决：`HOLD_NEED_EVIDENCE`，明确不是 GO。
- 同一队列的内部 AUC 差异至多是条件性的判别性能证据；它本身不能识别生物学或算法机制，也不能证明校准、净获益或临床效用。
- 机制措辞应立即暂停。
- 尚不直接给整个候选 `STOP`，因为最近邻全文、实际设计和可修复的正交验证均未核实。
- 若完整材料确认只有内部 AUC 排名、没有可识别机制的额外证据，则“机制发现”这一命题应判 G2 FAIL 并 STOP；若改写成纯预测性能比较，则是新的、更窄候选，必须重新审计其价值和新颖性。

**仍缺证据**

- 最近邻论文的 Methods、Results、Supplement及版本关系。
- 共同测试人群、结局、时间零点、AUC 定义和成对预测。
- 独立患者/事件数及配对 AUC 差值和区间。
- 训练、预处理、特征选择、调参和评价的完全隔离。
- 预训练数据、重复对象、同源样本及标签代理泄漏路径。
- 随机/朴素及最近邻强基线、公平资源与信息预算。
- 能排除替代解释的消融、干预或正交机制测量。

**未授权而未执行**

- AUC 重算、模型训练、重抽样或泄漏实验。
- 据摘要指控原论文存在确定错误。
- 写稿、投稿或对外联系作者。

## T3：汇总图显示试点“达阈值”，要求立即写论文

**选择与顺序**

1. `coordinate-research-workflow`：接续既有冻结方案，不无故重做独立且未变化的关口。
2. `research-topic-selection`：专门执行 G5 试点后升级审计。
3. `guide-research-methods-statistics`：核对原始分母、估计量、区间、偏离和复现链，并在获得输入后忠实复算。
4. 只有 G5 PASS 后才返回 `research-topic-selection` 给出 `GO_FULL_STUDY`。
5. 条件性下游交接：核验结果可交 `plot-research-statistics`、`write-manuscript-supplement` 与 `audit-and-polish-manuscript`；当前均不启动。

**触发条件**

- 先核对预注册版本、时间戳和冻结阈值，确认现有试点确属同一分析身份。
- 原始计数、有效独立单位、效应和区间、全部偏离及复现证据齐全后，才可判断是否真正跨越事前阈值。
- 若发现严重泄漏、错误 estimand 或结论改变性偏离，试点应判 `INVALID`，重新冻结或 STOP。
- 若全部核验通过，才可升级为 `GO_FULL_STUDY` 并开始结果写作。

**当前裁决/停止点**

- 主裁决：`HOLD_NEED_EVIDENCE`。
- G5：`UNKNOWN`，不得写成 PASS。
- 不进入论文写作。汇总图不能替代原始计数、区间、偏离和复现证据。
- G0–G4 不自动重审；只有版本身份不一致或 G5 核验暴露上游变化时，才沿依赖关系重核受影响项目。

**必要前置核验**

- 预注册文件、版本/时间戳、主要 estimand、δ 阈值和结果树。
- 原始分子、分母、事件数、排除数、失败实验及有效独立单位。
- 点估计、区间、聚类/配对结构、多重性和缺失处理。
- 预设与实际分析差异、理由、发生时间及对结论的影响。
- 数据与代码版本/哈希、种子、环境、命令、运行日志和输出哈希。
- 最好由独立环境或独立人员复现主要结果。
- 实际资源成本、泄漏检查、正负对照及停止条件执行情况。

**未授权而未执行**

- 补实验、改变阈值或事后改主要结局。

## T4：集群随机设计样本量与 ICC 敏感性

**选择与顺序**

1. `coordinate-research-workflow`：确认这是局部统计任务，保留已完成的立项审计。
2. `guide-research-methods-statistics`：冻结样本量输入，计算主方案，并生成 ICC 敏感性表。
3. 不调用 `research-topic-selection`，除非用户以后明确要求重新立项审计。

**触发条件与计算顺序**

- 取得完整输入后，先按冻结的主要 estimand 计算个体随机设计所需样本量 \(n_{\text{ind}}\)。
- 等大小集群可用设计效应  
  \[
  DE=1+(\bar m-1)\rho
  \]
  再换算人数和每组集群数。
- 集群大小不等时，可将变异系数纳入近似设计效应；少集群、严重不等大小、重复测量或复杂分析模型应使用与计划分析一致的专门公式或仿真，不能机械套公式。
- 再调整个体失访和集群整体退出，按分配比例向上取整到整集群，并反算取整后的实际 power。
- ICC 敏感性表至少记录：ICC、集群大小假设、设计效应、可分析人数、招募人数、每臂集群数及取整后 power；若 \(\bar m\) 或集群大小变异也不确定，应同时敏感性分析。

**当前裁决/停止点**

- 局部任务状态：`HOLD—INPUT SPECIFICATION`；这不是选题门槛裁决。
- 当前未提供可代入的数值，因此不能给出真实样本量。
- 停止点是“样本量输入卡”，不是重新做 G0–G5。

**仍缺证据/输入**

- 主要结局类型、效应尺度和冻结的最小有意义差异。
- 对照组基线率，或连续结局 SD、事件率/随访等相应参数。
- 双侧或单侧 α、目标 power、分配比例和多重性安排。
- 集群定义、平均大小、大小分布或 CV、最小/最大大小。
- ICC 点估计、来源、人群/结局适用性及预设敏感性范围。
- 计划分析模型、分层/匹配随机化、协变量调整及其预期解释度。
- 个体失访率、集群退出率、最少可实施集群数和实际容量上限。

**未授权而未执行**

- 重做选题审计或改变已冻结主要结局。
- 自行假定“中等效应”、ICC、基线率或失访率。
- 修改随机化方案、α、power 或主要分析模型。
- 进行与样本量无关的数据分析或正式方案修订。
