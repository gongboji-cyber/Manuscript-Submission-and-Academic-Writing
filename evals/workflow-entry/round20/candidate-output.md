## T1｜拒稿后是否补实验，以及当前结果段审查

### 裁决与边界

- **创新性/是否值得补实验：`NOT_RUN / HOLD`。**
- 负责最近邻前作、数据资格、可证伪试点和止损裁决的 `research-topic-selection` 当前不可用，因此不能据现有一句背景信息判断“值得重做”，也不能用语言润色或稿件审查替代创新性裁决。
- 在创新性关口完成前，不建议直接投入完整补实验。应先明确：最近邻研究相比之下新增了什么可检验命题、公开数据是否允许支持该命题、能否取得独立证据、最小试点成功阈值和停止条件是什么。

当前未提供结果段、图表、方法或数据，因此只能建立待核清单；以下均为“**无法核实**”，不是已发现错误，也不应判为“不通过”。

| 待核项 | 状态 | 需要的材料 |
|---|---|---|
| 每个主要结果是否对应预先定义的结局、分析和分母 | 无法核实 | Methods、方案/注册、Results |
| 正文、表格、图和补充材料中的数值、方向、单位、时间点是否一致 | 无法核实 | 完整结果段及全部图表 |
| 均值/中位数、SD/SE/CI、绝对/相对效应是否标注正确 | 无法核实 | 结果表、统计输出 |
| 样本数、排除、缺失和各分析分母是否守恒 | 无法核实 | 纳排记录、分析样本说明 |
| P 值、区间、多重性处理是否与方法一致 | 无法核实 | SAP、代码或统计输出 |
| 公开/合成数据的来源、许可、生成方式及独立性是否足以支持主张 | 无法核实 | 数据说明、来源和生成流程 |
| 结果是否越界为因果、机制、临床效用或泛化结论 | 无法核实 | 结果原文及研究设计 |
| 阴性结果、失败分析、异质性和不确定性是否完整呈现 | 无法核实 | 完整结果及补充材料 |
| 术语、组名、缩写、时态和效应方向是否稳定 | 无法核实 | 结果原文 |
| 是否夹入讨论性解释，或用“显著”代替效应大小与精度 | 无法核实 | 结果原文 |
| 句子是否准确、克制、简洁，逻辑顺序是否按问题—估计—区间展开 | 无法核实 | 结果原文 |

解除边界至少需要：结果段、方法段、对应图表/补充材料、统计输出，以及用于创新性判断的最近邻研究与拟补实验方案。拿到这些材料后，应先完成主张—证据对应，再处理语言；不能通过润色掩盖证据缺口。

## T2｜连续主要结局的 SAP 框架

项目已获批、正式立项，且目标、样本和主要结局已冻结，因此选题模块依赖不适用。本次可直接制定条件性 SAP；由于没有原始数据，所有分析均标为“**未执行**”。

### 1. 版本与治理

- 项目、负责人、SAP 版本、UTC 日期。
- 伦理批准、方案和注册编号；冻结日期及审批角色。
- 注明 SAP 是结果未知时事前制定，还是结果已知后的追溯性文件。
- 修改规则、偏离记录位置，以及每次修改时研究团队已知哪些结果。

### 2. 研究问题与目标量

预先写明：

- 目标人群、研究设计、暴露/干预、比较条件。
- 连续主要结局的精确定义、单位、方向、测量工具、时间零点、评估窗口和主要时间点。
- 最小临床重要差异或精度目标及其来源。
- 独立分析单位，以及配对、重复测量、中心聚类或其他依赖结构。
- 主要效应尺度，例如原量纲均值差及 95% CI。
- 若为临床试验，按五属性写明 estimand：人群、干预/比较、结局变量、中间事件策略和总体汇总量；区分 estimand、estimator 与最终 estimate。
- 若为非随机研究，明确是描述、关联还是因果问题；没有充分识别条件时不得使用因果措辞。

### 3. 分析集与数据规则

- 定义主要分析集、纳排规则、去重规则及各阶段分母。
- 说明基线值、随访值、无效测量、量程错误和重复记录的处理。
- 不按观察到的结果自动删除异常值；数据无效规则须事先定义。
- 记录数据字典、版本、哈希和派生变量规则。
- 样本量依据使用设计阶段的效应、方差、失访、聚类等假设；不补做 observed power。

### 4. 主分析 A01

具体模型应由设计决定，不按正态性检验或结果显著性自动切换：

| 设计结构 | 可预设的主估计方法 |
|---|---|
| 两个独立组、单一主要随访时点 | 线性回归或 ANCOVA；结局为因变量，组别为核心自变量，基线结局及预设协变量作调整 |
| 同一对象前后配对 | 配对差的均值及区间，或等价的配对模型 |
| 多个重复时间点 | 混合模型、GEE 或与目标量一致的重复测量模型；预先指定组别、时间、交互及主要时间点对比 |
| 存在中心/家庭等聚类 | 能保留该依赖结构的混合模型、GEE、设计型方差或层级重抽样 |

A01 至少冻结：

- 目标量及权重；
- 纳入分母；
- 模型公式和协变量的领域依据；
- 连续协变量的功能形式，是否使用预设样条或交互；
- 效应估计、95% CI及必要的检验；
- 失败信号与补救路径；
- 解释边界。

### 5. 缺失数据与中间事件

- 列出主要结局和协变量的缺失定义与时间模式。
- 说明主要机制假设和主策略；失访不能简单等同于删除。
- 插补模型须与分析模型、分组、时间和交互结构兼容。
- 预设针对 MNAR 的敏感性分析，如 delta 调整、模式混合或 tipping-point 分析；具体选择由研究设计决定。
- 完整病例分析若使用，应说明其额外假设和样本损失，通常不作为无条件默认方案。

### 6. 诊断、敏感性和补充分析

- 检查残差、功能形式、异方差、影响点、收敛和边界估计。
- 不以 Shapiro–Wilk 或 Levene 检验的单个 P 值作为自动换方法的开关。
- 针对同一 estimand 预设稳健标准误、稳健回归或替代分布假设等敏感性分析。
- 把改变 estimand 的分析单列为补充分析，不能与主分析互换。
- 亚组仅按预设交互检验；“一组显著、另一组不显著”不构成亚组差异。
- 一个冻结的主要结局和主要时间点可形成单一主要检验族；若另有多个主要时间点或共同主要结局，须预先确定多重性策略。

### 7. 报告与审计

- 报告每项分析的有效独立样本数和分母。
- 同时报效应估计、区间和原量纲临床意义，不只报告 P 值。
- 区分统计显著性与临床重要性；区间跨零不等于证明无效。
- 保存运行命令、环境、代码版本、种子、输入/输出哈希、模型失败和偏离记录。
- 数据到位前不填写结果，也不声称分析、诊断或复现已经完成。

## T3｜单 panel 折线图执行与验收计划

### 图形定义

- 问题：不同 `treatment` 的汇总均值如何随 `time` 变化，其不确定性如何。
- 映射：`time` → x 轴，`mean` → y 轴，`treatment` → 颜色，并辅以不同线型或点形；`lower`、`upper` → 已核实的置信区间。
- 图型：每组使用点加折线，并显示 CI 带或区间线。
- 仅有汇总值，因此不生成原始散点、箱线图或小提琴图，也不从均值和区间反推伪样本。
- CI 水平和计算方法若未提供，只标作“CI，定义待确认”，不能擅自写成 95% CI。

### 执行步骤

1. 锁定 CSV 版本并记录哈希；核对五列存在、数值类型和单位。
2. 检查每个 `treatment × time` 是否唯一；重复行不静默平均。
3. 检查有限数值及 `lower ≤ upper`。估计值不在区间内时保留原值并列为待确认，不擅自修正。
4. 明确 `time` 是连续量还是有序类别；按核定顺序排序。
5. 对缺失时间点断线，不插值、不平滑、不跨缺口连接。
6. 绘制单一主要坐标轴；不新增检验、P 值、星号或重新计算 CI。
7. 使用克制且可区分的配色，并用线型/标记提供冗余编码；图例置于绘图区外且画布内。
8. 以约 89 × 70 mm 为起点，在最终尺寸检查字号、轴单位、线宽和图例；根据内容调整尺寸。
9. 保存独立可运行代码、配置、输入来源/哈希、依赖版本和重运行命令。
10. 若实际执行，导出白底 RGB/LZW 800 dpi TIFF及单页矢量 PDF；本任务目前不要求执行，故产物状态为“未生成”。
