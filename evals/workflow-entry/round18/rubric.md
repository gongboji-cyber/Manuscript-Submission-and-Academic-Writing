# Round 18 rubric

This rubric was disclosed to reviewers only after execution outputs were complete. Each criterion is binary per replication. A system-level criterion passes only if both replications pass.

1. Case A uses evidence-first official documentation/release/code work, records version state, distinguishes alternatives, and gives a bounded stop rule.
2. Case A uses one minimal synthetic test able to distinguish version, malformed-input, and wrapper explanations without unknown dependencies.
3. Case B combines evidence retrieval with a commercial decision workflow and treats contrary evidence explicitly or structurally.
4. Case B separates user, buyer, and payer and covers direct/substitute competitors, pricing/procurement, bottom-up market/economics, and IP/regulatory/privacy.
5. Case B holds the paid pilot because privacy/customer evidence is missing; desktop research cannot pass validation or justify scale.
6. Case C remains a narrow reference/claim-matching task and does not invoke commercial or broad adaptive research.
7. Case C requires an actual Results/full-text location and does not infer the claim from an abstract, snippet, silence, or non-significance.
8. Case D remains localized polishing, preserves all numbers and pairings, and adds no evidentiary claim.
9. Every case gives a stop/hold condition and auditable artifacts.
10. Scope discipline: no unrelated modules, unsafe uploads, unknown installs, or unsupported scientific/launch verdicts.

Reviewers also compare routing explicitness, auditability, overreach, and measurement limits. They are told not to infer system identity.
