# Round 17：流程图分流的前向行为验证

日期：2026-10-16

## 具体缺陷与完成条件

Round 16 只完成静态版本接续，没有验证 agent 在真实任务中能否区分统计图、精确流程图、专利内容工作和无需作图。完成条件是：同一模型条件、同一四个公开合成输入下，候选输出经两名不知道版本身份的独立复核；正常、边界、不适用任务均无证据伪造或假验收。

## 方法

- X 为无仓库上下文基线；Y 只读取 `5e6e1eb9b2081635c847580f6460b1547ba10dda` 的根入口和完成任务所需的最少模块。
- 执行者只收到原始任务，不收到诊断、量表或答案。两组输出完成后才冻结量表。
- 两名新的复核者收到逐字匿名输出和量表，不访问仓库或网络。
- 第一次评分输入因人工摘要漏掉 X 的 `单panel` 而作废；随后用逐字输出重评。

## 结果

- 候选 Y：两名复核者均为 9/10。
- 基线 X：6/10 与 8/10；差异来自对检查状态和描述性模块名称是否足够可交接的严格度。
- 两名复核者均确认 Y 的增益在于：稳定模块路由；专利内容与附图制作分工；实际打开 SVG 后才完成视觉验收。
- 两名复核者均指出 Y 的残余失败：`不新增检验` 没有明确到 `不合并队列、不计算汇总效应、不自行做meta分析`。

## 改动决定

本轮不修改运行 skill。现行 `plot-research-statistics` 已明确写有 `do not ... recompute unapproved analyses`、`只绘图不擅自新增检验或重算已冻结结果`；Y 也写明只用现有效应量且不新增检验。残余失败属于一次输出压缩偏差，尚不足以证明运行规则缺失。继续添加同义禁令会增加运行时文字而没有独立证据证明可改善执行。只归档这次前向评测和失败信号。

## 测量边界

- 每个版本仅一次四任务批次；不能估计成功率、方差或显著性。
- 没有真实 TIFF/PDF/SVG 输入与导出，因此没有完成图像渲染或视觉质量验证；只验证计划与停止规则。
- 精确模型部署 ID、token、费用和可比耗时不可得。
- 结果不认证统计、专利法律意见、科学正确性、期刊合规或一般可靠性。

## 下一步与重查条件

仅在后续真实或合成运行再次出现未经请求的合并效应/meta分析，或把未打开的图文件宣称已通过时，才考虑把对应限制升级为强制输出字段并做同条件复测。流程图或统计作图模块版本、模块 stable name、导出合同发生变化时也应重跑本组案例。
