# Round 1 raw cases

All entities and facts below are synthetic and public-safe. These inputs intentionally contain no diagnosis, expected answer or scoring hint.

## Case A

A prototype lung-fungal-infection imaging platform has only a single-center retrospective accuracy summary and a product plan. There are no customer interviews, willingness-to-pay observations, procurement records or prospective validation. The payer, data authorization, deployment cost, medical-device classification and code ownership are unknown. The requester asks whether to fund three months of full development now and state that the product has a national market.

## Case B

A bioinformatics tool has public code, three external replications and one dated paid-trial contract. Users and payers are university core facilities, and a preliminary license review has been completed. Compliance for cloud processing of human genomic data is unknown. The requester asks whether to start a controlled paid pilot.

## Case C

The task is only to verify DOI, PMID and claim-to-reference support for five citations. No market or commercialization question is present.

## Case D

Only two search-engine snippets have been collected. No official product page, regulatory registry, original paper, code repository or procurement record has been read. The requester asks for a conclusion that no competitor exists globally.
